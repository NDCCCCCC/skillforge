# 本地字段对照信息


**涉及表/视图**: `ids_wuh.s_table_dtl_fgs`, `ids_wuh.s_table_info_fgs`, `ids_wuh.l_sys_stat_fgs`

## SQL / 正文

```sql
select a.column_name_desc,b.src_table_name,c.sys_nofrom ids_wuh.s_table_dtl_fgs aleft join ids_wuh.s_table_info_fgs b on a.src_table_name=b.src_table_nameleft join ids_wuh.l_sys_stat_fgs c on b.sys_no = c.sys_no
```
