# 承保清单


**涉及表/视图**: `wuh_dw.etl_nonauto_policy_t`, `ids_wuh.NONAUTO_PEOPLE_T`

## SQL / 正文

```sql
selecta.TOTAL_INSURED_AMOUNT 起保保费,a.premium_amount 起保保费,  (select max(b.factor_value)           from "ids_wuh".nonauto_plc_element_t b         where b.policy_no=a.policy_no           and b.factor_code='M9') 学校名称,a.OPERATOR_NAME 经办人,a.SELLING_CHANNEL_TYPE 渠道代码,a.tb_name 投保人,a.tb_credential_no 投保人证件号码,a.bb_name 被保险人,a.bb_credential_no 被保险人证件号码,a.INCEPTION_DATE 保险起期,a.PLANNED_END_DATE 保险止期,a.POLICY_NO 保单号,a.product_name 险种名称,a.DEPARTMENT_NAME 部门,a.AGENT_NAME 代理人,c.WARDNAME 被监护人姓名,c.CERTNO 被监护人证件号码from wuh_dw.etl_nonauto_policy_t aleft join ids_wuh.NONAUTO_PEOPLE_T c on a.policy_no = c.policy_nowhere a.product_code in ('24489800','1107DS00','1107IX00')and a.department_group_name = '襄阳中心支公司'and a.inception_year = '2025'che
```
