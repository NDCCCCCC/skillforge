# 子险、附加险、明细险种代码保费信息


**涉及表/视图**: `ids_wuh.NONAUTO_COVERAGE_COMPONENT_T`, `xzh`

## 说明

NONAUTO_COVERAGE_COMPONENT_T 非车子险保费表

## SQL / 正文

```sql
select a.policy_no,a.ENDORSEMENT_NO,POLICY_PRODUCT_CODE 保单险种代码,h.PRODUCT_name 保单险种名称,a.PRODUCT_CODE 明细险种代码,s.PRODUCT_name 明细险种名称,a.premium_amount 明细险种保费 ,a.insured_amount 明细险种保额from ids_wuh.NONAUTO_COVERAGE_COMPONENT_T a left join xzh s on a.PRODUCT_CODE=s.PRODUCT_CODEleft join 饿 h on a.POLICY_PRODUCT_CODE=h.PRODUCT_CODEwhere a.policy_no='AWUHC212C724PAAAAA22'and a.ENDORSEMENT_NO='无';
```
