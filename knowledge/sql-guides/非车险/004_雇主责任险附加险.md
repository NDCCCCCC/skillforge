# 雇主责任险附加险


**涉及表/视图**: `IDS_WUH.nonauto_item_list_t`, `etl_nonauto_policy_t`

## SQL / 正文

```sql
select a.policy_no,b.department_group_name,b.tb_name,b.INCEPTION_DATE,b.PLANNED_END_DATE,c.itemname from IDS_WUH.nonauto_item_list_t aleft join IDS_WUH.nonauto_item_list_t c on a.policy_no=c.policy_noleft join etl_nonauto_policy_t b on a.policy_no=b.policy_noWHERE a.itemcode= 'LHEL033C'and b.INCEPTION_DATE >= date('2025-07-01 00:00:00')and b.INCEPTION_DATE < date('2026-08-01 00:00:00')and b.product_name = '雇主责任险'
```
