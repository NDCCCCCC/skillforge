## 说明



基于 Go + Wails 的桌面定时任务管理应用。支持 exe/bat/sql/web 任务，自定义消息模板，条件发送通知，后置动作联动。部署目录：C:\Cron一、快速开始1.1 文件夹组织创建文件夹：点击顶部"新建文件夹"，或右键菜单选择"新建子文件夹"重命名：双击文件夹名称，或右键选择"重命名"展开/折叠：点击文件夹左侧箭头（▼/▶）移动任务：拖拽任务到文件夹图标上批量操作：右键文件夹可选择"批量启用"或"批量禁用"删除文件夹：右键选择"删除"，会级联删除所有子内容1.2 创建任务点击"新建任务"，填写：字段必填说明任务名称是便于识别的名称任务描述否记录任务用途执行类型是EXE / BAT / SQL / 网页截图选择文件是从 bin 目录选择Cron 表达式是执行时间规则重试机制否失败后重试次数和间隔1.3 任务操作按钮功能▶ 立即执行手动触发任务运行⏸ 启用/禁用暂停或恢复自动执行✎ 编辑修改任务配置📋 查看日志查看执行历史🗑 删除删除任务（需确认）1.4 Cron 表达式格式：秒 分 时 日 月 周（6位）表达式说明0 * * * * *每分钟0 */5 * * * *每5分钟0 0 * * * *每小时0 0 */2 * * *每2小时0 0 0 * * *每天零点0 0 8 * * 1-5工作日早8点0 0 9,18 * * *每天9点和18点0 0 0 1 * *每月1号零点0 0 0 * * 0每周日零点二、任务类型详解2.1 可执行程序 (EXE)支持 .exe、.bat、.cmd，文件须放在 bin/ 目录自动捕获标准输出和错误输出2.2 批处理脚本 (BAT)支持 .bat、.cmd 脚本，须放在 bin/ 目录自动捕获脚本执行结果2.3 SQL 脚本支持数据库：MySQL、PostgreSQL、SQL Server、GaussDB、SQLite在"设置→数据库配置"中预先配置连接信息支持多行 SQL 脚本，查询结果作为任务输出2.4 网页报表截图每行一个 URL，支持批量截图可为每个 URL 指定分辨率（如 1920x1080）支持 PNG 和 JPG 格式可设置等待超时时间图片以 base64 格式存储在执行记录中三、通知功能3.1 发送方式邮件通知：选择已配置的 SMTP 服务器API 通知：选择已配置的 Webhook 接口3.2 接收人管理搜索接收人 → 点击选择 →
