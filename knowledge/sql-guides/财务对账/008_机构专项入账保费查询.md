# 0人1人机构专项入账保费查询


**涉及表/视图**: `wuh_dw.etl_payment_due_t`

**输出字段示例**: 2024整体入账保费(万元), 2025整体入账保费(万元), 2024车险入账保费(万元), 2025车险入账保费(万元), 2024非车非农入账保费(万元), 2025非车非农入账保费(万元), 2024农险入账保费(万元), 2025农险入账保费(万元)

## SQL / 正文

```sql
SELECT     section_office_name    ,ROUND(SUM(CASE WHEN nf = '2024' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2024整体入账保费(万元)"    ,ROUND(SUM(CASE WHEN nf = '2025' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2025整体入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '车险' AND nf = '2024' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2024车险入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '车险' AND nf = '2025' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2025车险入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '非车险' AND nf = '2024' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2024非车非农入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '非车险' AND nf = '2025' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2025非车非农入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '农险' AND nf = '2024' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2024农险入账保费(万元)"    ,ROUND(SUM(CASE WHEN xzdl = '农险' AND nf = '2025' THEN rzbf_with_tax ELSE 0 END)/10000, 1) AS "2025农险入账保费(万元)"FROM wuh_dw.etl_payment_due_tWHERE section_office_name LIKE '%营销服务部%' OR section_office_name IN ('竹溪支公司','远安支公司')GROUP BY section_office_nameORDER BY section_office_name
```
