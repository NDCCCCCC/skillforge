# 计提手续费


**涉及表/视图**: `etl_payment_due_t`, `v_case_1`

**输出字段示例**: 部门

## SQL / 正文

```sql
with v_case_1 as(SELECTa.policy_no 保单号,a."endorsement_no" 批单号,a.department_grouP_code 部门组代码,a.department_group_name 部门组,a.department_code 部门代码,a.TJBMMC AS 部门,sum(a.rzbf_notax) 入账保费,max(to_date(a.dd,'yyyy-mm-dd')) 入账时间FROM etl_payment_due_t agroup by a.policy_no,a."endorsement_no",a.department_grouP_code,a.department_group_name,a.department_code,a.TJBMMC)select a.*,t.kq 客群,t.operator_name 经办人,t.operator_code 经办人工号,t.product_code 险种代码,t.product_name 险种名称,t.xzhdlmc 险种大类,t.insured_amount 保单保额,t.issue_date 保单签单日期,t.inception_date 保单起保日期,t.planned_end_date 保单终止日期,t.SELLING_CHANNEL_TYPE 展业方式代码,t.SELLING_CHANNEL_NAME 展业方式名称,t.eight_channel 渠道,t.AGENT_CODE 代理点代码,t.AGENT_NAME 代理点名称from v_case_1 a,etl_nonauto_policy_t twhere a.保单号=t.policy_noand t.class_name = '团客'),
```
