# 入账保费TOP50


**涉及表/视图**: `wuh_dw.etl_payment_due_t`, `wuh_dw.etl_nonauto_policy_t`

**输出字段示例**: 入账保费

## SQL / 正文

```sql
select DISTINCT a.product_name 险种类型, sum(a.rzbf_with_tax) as 入账保费  from wuh_dw.etl_payment_due_t a  left join wuh_dw.etl_nonauto_policy_t b on a.policy_no = b.policy_no  where a.nf = '2025'  AND(b.partner_name like '%官微%' or b.partner_name like '%码上保%') group by a.product_name order by 入账保费 desc
```
