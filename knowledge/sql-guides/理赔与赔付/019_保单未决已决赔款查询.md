# 查询指定保单号的未决，已决赔款


**涉及表/视图**: `tmp_cc_002`, `ids_wuh.AUTO_CF_INDEMNITY_T`, `ids_wuh`

**输出字段示例**: 已决赔款, 未决赔款

## SQL / 正文

```sql
select a.bdh,nvl(c.yjpf,0) as 已决赔款, nvl(e.gsje,0) as 未决赔款 from tmp_cc_002 aleft join (select policy_no, SUM(insured_object_indemnity + investigation_fee + investigation_agent_fee + inside_investigation_agent_fee + claim_audit_fee + salvage_fee + other_fee - salvage_recovery) as yjpf               from ids_wuh.AUTO_CF_INDEMNITY_T              WHERE TRUNC(POSTED_DATE) <= TRUNC(to_date('2025-12-31 23:59:59'))              and TRUNC(POSTED_DATE) >= TRUNC(to_date('2025-01-01 00:00:00'))              group by policy_no               ) c on c.POLICY_no = a.bdhleft join  (select polno,sum(gsje) gsje from ids_wuh."indispute_t_1214" where nf = '2025' and qsh = '12' group by polno) e on e.polno=a.bdh
```
