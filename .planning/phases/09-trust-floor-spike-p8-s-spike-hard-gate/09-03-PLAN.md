新建 `cmd/spike-history/runner.go`（`package main`，license header + 顶部 godoc 引用 GEVL-08 + RunEntry 签名 + dry-run 路径）：

(1) **类型定义**：
```go
type runnerDeps struct {
    Embedder  embedder.Embedder
    Retriever retriever.Retriever
    Manifest  *skill.Manifest
    ChatModel model.ToolCallingChatModel
    Judge     eval.Judge
    DryRun    bool
}

type costState struct {
    TotalUSD float64
    LimitUSD float64
}

func (c *costState) Record(msgs []*schema.Message) {
    if c == nil || c.LimitUSD <= 0 { return }
    var bytes int
    for _, m := range msgs { bytes += len(m.Content) }
    c.TotalUSD += float64(bytes) / 2.0 / 1e6 * glmPricePerMTokUSD
}
func (c *costState) Exceeded() bool { return c != nil && c.TotalUSD >= c.LimitUSD }
const glmPricePerMTokUSD = 0.10
```

(2) **RunEntry 签名**：
```go
func RunEntry(
    ctx context.Context,
    row SpikeRow,
    withHistory bool,
    historyLen string,            // "short" | "long"（Plan 09-03 只接受 short）
    deps *runnerDeps,
```

(3) **RunEntry 主体**（镜像 cmd/eval/main.go:373-490 但拆 4 个 step）：

- **Step 1 — history 投影（withHistory=true 才做）**：若 `withHistory && len(row.HistoryTurns) > 0`，把 `row.HistoryTurns` 翻 `[]store.SessionMessage`，调 `history.Project(...)` 得 `[]schema.Message`，转 `[]*schema.Message`（直接取地址；plan 09-02 返回的是 pointer slice）暂存为 `projected`；否则 `projected = nil`。**`historyLen == "long"` 在此步先 return error**（stub gate）。

- **Step 2 — preRetrieve 检索**：用 `deps.Embedder.Embed(row.Query)` 得 queryVec；调 `deps.Retriever.Search(ctx, queryVec, deps.Manifest.ResolvedTiers(), topK=5, now)` 得 hits。dry-run 模式：构造 stub retriever 用的 5 条 dummy hits（内容 = `fmt.Sprintf("[DRY chunk %d] for query %s", i, row.Query)`，chunkID 形如 `"9991"`.."`9995"`）。同步构造 `acc := agent.NewChunkAccumulator()`，调用 `acc.Add(hits)`。

- **Step 3 — 拼 messages**：
```
sys := &schema.Message{Role: schema.System, Content: agent.RenderSystemPrompt(deps.Manifest)}
user := &schema.Message{Role: schema.User, Content: buildUserMessageBody(row.Query, hits, projected, withHistory)}
```
- `buildUserMessageBody` 私有 helper：当 `projected` 非空且 `withHistory=true` 时，把 projected 按顺序串到 query 之前（前缀"以下是历史对话...\n"），否则只拼 query + preRetrieve chunks（与 `internal/agent/agent.go:680` 同构）。**历史前缀与 preRetrieve chunks 不混淆**：历史段顶部加注释 `<!-- 历史上下文（非证据，仅作指代解析） -->`；preRetrieve chunks 顶部加 `<!-- 本轮检索（唯一证据源） -->`。

- **Step 4 — 调 chat model**：用 `deps.ChatModel.Generate(ctx, []*schema.Message{sys, user})`（dry-run 模式：构造 stub Verdict{Status:"ok", Confidence:0.9, Citations:[{ChunkID:"9991", Span:"DRY"}], ReviewRequired:false, Answer:row.Query, ComplianceStatus:""}）；返回后调 `verdict.Validate(v)`，失败 → result.Refused=true + result.Metrics 全 0。

- **Step 5 — trust floor + grounding**：
- 调 `agent.ApplyTrustFloor(acc, row.Query, deps.Manifest.ResolvedTiers())` —— 若返回 refusal（非 nil）→ result.Refused=true（不解析 verdict）+ return（metrics 全 0 即可）

- **Step 6 — 4 指标**：
- `answer = json.Marshal(v)` （与 cmd/eval:438 同构）
- `contexts = []string{}` + 遍历 `acc.TierMatched()` 累加 content
- 顺序调：`eval.Faithfulness(ctx, answer, contexts, deps.Judge)` + `eval.AnswerRelevancy(ctx, row.Query, answer, deps.Embedder, deps.Judge)` + `eval.ContextPrecision(ctx, row.Query, hits, deps.Judge)` + `eval.ContextRecall(ctx, row.GroundTruth, hits, deps.Judge, result.Refused)`
