## Color

继承 40-UI-SPEC §Color 全表（60/30/10 + `--color-status-*` 语义映射）。**本 phase 唯一新颜色决策：layer 徽章映射**（D-46-03 授权 ui-phase 域）。layer 是**分类徽章**（不是 severity——severity 徽章已存在且不动），用分类家族色，不复用红/黄 severity 语义：

| Layer value | Badge label | Classes | 家族依据（40-UI-SPEC 先例） |
|-------------|-------------|---------|------------|
| `tbox` | `TBox` | `bg-primary-dim text-primary` | indigo = schema/emitter/induction 家族（who:induction:llm、source_kind:induction 同族） |
| `entity` | `实体` | `bg-surface-3 text-text-muted` | neutral = 数据家族（who:admin、source_kind:emitter 同族） |
| `global`（哨兵） | `跨实体` | `border border-dashed border-border text-text-muted`（透明 bg） | dashed = 跨界/哨兵语义（quarantined 图节点 dashed 先例）；不引入新语义色 |
| 未知/未来 layer 值 | 原始字符串 | `bg-surface-3 text-text-muted`（同 entity） | console honesty：未知枚举渲染原值，不吞不猜 |

**Accent（`--color-primary`）预留用途不变**（40-UI-SPEC reserved-for 列表有效）；`tbox` 徽章用 `primary-dim` 底是既有 `bg-primary-dim text-primary` 组合 idiom（view-switcher active / who:induction 徽章），非 accent 新用途。

**target_class 不是彩色徽章**：渲染为 neutral chip `rounded bg-surface-2 px-1.5 py-0.5 text-[11px] text-text-muted` + mono IRI——避免每行两个彩色徽章的噪声；layer 徽章是唯一彩色分类元素。

| Role | Value | Usage（本 phase 增量） |
|------|-------|----------------------|
| Dominant (60%) | #0c0e12 (`--color-bg`) | 不变 |
| Secondary (30%) | #14171e (`--color-surface`) | 不变（表头 `bg-surface-2`、chips `bg-surface-2`） |
| Accent (10%) | #6366f1 (`--color-primary`) | 不变（`tbox` 徽章用 primary-dim/primary 组合，既有 idiom） |
| Destructive | #ef4444 (`--color-danger`) | 不变（隔离区行实体 IRI 已用；本 phase 零新用途） |

## Component Inventory (delta)

### 1. `types.ts` — DTO 扩展（FE snake_case 镜像，BE omitempty → FE optional）

```typescript
export type ViolationLayer = 'tbox' | 'entity' | 'global';

export interface ShaclViolation {
  // …既有字段不动（severity/entity/constraint/detail/source_path?/line_start?/line_end?）…
  /** D-46-03: validate.go stamping 点盖戳；legacy/未盖戳 violation 缺省 */
  layer?: ViolationLayer;
  /** NodeShape TargetClass（skf:InsuranceProduct / skf:Organization / skf:NoteChunk …）；layer=global 时缺省 */
  target_class?: string;
}

export interface QuarantinedEntity {
  // …既有字段不动…
  /** D-46-04: 只读计数——指向该隔离实体的入边数量（对象位可见）；BE 未下发时缺省 */
  dangling_edge_count?: number;
}
```

`ShaclReport` 零变化（D-46-02：`shapes_path` 保持单 string，BE join 显示，FE 类型不动）。

### 2. `ShaclReportView.tsx` — 行内徽章

每条 violation 行（红区按 quarantined 实体首条 violation、黄区按 warning 行）的**约束 cell** 变为三层结构：

```
│ 约束                                                        │
│ [TBox] [skf:NoteChunk]  sh:minCount  +2                     │
│  彩色徽章  neutral chip   mono        muted +n              │
```

- 渲染顺序：layer 徽章 → target_class chip → constraint（mono）→ `+{extra}`。
- `layer` 缺省（legacy 未盖戳）→ 不渲染徽章，直接 constraint（向后兼容，40 报告 shape 不炸）。
- `target_class` 缺省（global 哨兵）→ 不渲染 chip。
- global 哨兵显示：layer=`global` 渲染「跨实体」dashed 徽章（§Color 表）；其行**没有** target_class chip——这就是哨兵的可视区分（跨实体完整性违规不属于任何单一 NodeShape 类）。
- severity 徽章既有 idiom 不动（本 phase 后 severity 徽章与 layer 徽章可并存于同一行——severity 管放不放行，layer 管哪一层，语义正交）。

### 3. `ShaclReportView.tsx` — 区头 per-layer 计数

红/黄区 `<h2>` 在既有标题文字后追加计数 chips（同一条 heading 行内，非新元素）：

```
隔离区（error 级违规实体）  TBox 2 · 实体 1 · 跨实体 1
警告（数据已放行）          TBox 0 · 实体 3
```

- 计数语义：该区内 violation 按 `layer` 分组计数（红区 = quarantined 实体的全部 violations；黄区 = `report.warnings`）。
- **只渲染非零 layer**，固定顺序 TBox · 实体 · 跨实体；全零不渲染 chips 行（理论不可达——区已渲染必有 violation）。
- 结构：`<span className="ml-2 font-mono text-xs font-normal text-text-muted" data-testid="governance-quarantine-layer-counts">`（黄区 `governance-warnings-layer-counts`）。计数是文本+mono，不依赖颜色承载。

### 4. `ShaclReportView.tsx` — 隔离区悬挂边列

隔离区表从 6 列变 **7 列**，「悬挂边」插在「三元组」之后：

| 列序 | Header | Cell | Style |
|------|--------|------|-------|
| 1 | 实体 | `entity` URI | mono, break-all, text-danger（不动） |
| 2 | 三元组 | `triple_count` | mono（不动） |
| 3 | **悬挂边**（新） | `dangling_edge_count` | mono；`!= null ? count : '—'`；**0 渲染为 0**（零悬挂边是有意义状态，不用 — 冒充）；header 加 `title="指向该隔离实体的入边数量（在 KG 查询对象位仍可见）"` |
| 4-7 | 约束 / 违规详情 / 来源 / 行号 | 不动（约束 cell 见 §2） | — |

黄区表列数不变（5 列；warning 行无隔离语义，无悬挂边）。

### 5. `GovernanceTab.tsx` — HealthBanner shapes meta（可选微调）

D-46-02 后 `shapes_path` 是 join 后的路径列表（含 os 分隔符）。既有 meta 行「shapes {shapes_path}」逐字渲染即可（FE 类型零变化），仅加显示保护：

```tsx
<span className="inline-block max-w-[280px] truncate align-bottom" title={report.shapes_path}>
  {report.shapes_path}
</span>
```

（280px = 4 的倍数；截断必须配 `title`——console truncate idiom。这是防止两路径 join 后把 banner 撑折的防御，非语义变更。）

### 6. 明确不动的部分

Tab 注册、view switcher、HealthBanner 三态文案与 Run ECL 回填 CTA、溯源图谱、版本演进、rollback 流、loading/error 骨架三件套、`governanceApi.ts` 的 null-guard 咽喉点（无新数组字段）。

## Accessibility

继承 40-UI-SPEC §A11y。本 phase 增量核对：

- Layer 徽章是**文字承载分类**（TBox/实体/跨实体），颜色非唯一载体——`tbox` 的 indigo 与 `entity` 的 neutral 即使色弱也可由文字区分；global 的 dashed 边框是文字之外的第二线索。
- 区头计数是 mono 文本（`TBox 2 · 实体 1`），不依赖颜色。
- 新表列 `th` 延续 `scope="col"`（现有表已如此渲染）；「悬挂边」header 的 `title` 补足缩写语义。
- 零新交互元素 → 零新键盘/焦点需求。
- 既有 `role="status"` + `aria-live="polite"` banner 不动；区头计数随报告一次性渲染，无需 live region。

## Honesty & Trust-Semantics Rules（增量红线）

继承 40-UI-SPEC 7 条红线，追加 2 条：

8. **悬挂边不粉饰。** `dangling_edge_count` 服务端下发多少渲染多少；字段存在时 0 必须渲染为 0；字段缺失渲染 —；FE 不计算、不估算、不猜测入边（计数是 store Query 的只读产物）。
9. **Layer 不倒推。** FE 只渲染 BE 盖的 `layer` 戳；禁止按 entity IRI 前缀/类名启发式前端分类（D-46-03 否决 FE-only 分组的同一理由——`OntologyGraphView.tsx:21-25` 硬编码债反例）。`layer` 缺省的 legacy violation 如实渲染为无徽章，不补猜。

- 不加新分区、不加 tab、不加 view switcher 项（D-46-03：标签问题）。
