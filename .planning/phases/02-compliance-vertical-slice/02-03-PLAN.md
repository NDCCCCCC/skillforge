<objective>
Wire the verdict pipeline end-to-end. This plan delivers the heart of Phase 2: a single POST /api/chat endpoint that takes {query, skill}, embeds the query via BGE-M3, retrieves 权威 chunks from Milvus via PRE-similarity tier filter, refuses BEFORE any LLM call if 0 chunks (refusal-by-construction D-09), otherwise prompts the ChatModelAgent at skill.Temperature, parses the JSON verdict, runs the D2-01 grounding checker, and emits an SSE stream with source-document chunks (per citation, SC-6) + a data-policy chunk (the Verdict or Refusal). Plus the cmd/server binary that hosts it (Pattern 1) and the knowledge indexer that loads the corpus from 02-02 into Milvus (Pattern 7).

Purpose: this is THE Phase 2 thesis proof. After this plan, a `curl -X POST localhost:8888/api/chat` with a compliance query returns either a grounded cited verdict or a structured refusal — the "Skill-as-platform" demo is real. The empty-tiers and low-score refusals are mechanically enforced (no improvising).

Output: runnable cmd/server binary; internal/server/{server.go, pipeline.go, chat.go}; internal/knowledge/indexer.go; the SC-2/3/4/5/6 test suite proving the pipeline behavior.
</objective>
