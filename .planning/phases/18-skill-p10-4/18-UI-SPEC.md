Red (`--color-danger`) is reserved exclusively for destructive confirmations per Phase 11 color contract.

## Wire Contract (Frontend Layer)

Phase 18 extends existing wire types. **Zero new SSE chunk types.** The `data-decision` discriminator is extended with `report_published` as an additive enum value (D17-B2 invariant).

```ts
// DecisionType — Phase 18 EXTENDS the existing union (not a new chunk type)
type DecisionType =
  | 'retrieve'           // existing
  | 'answer'             // existing
  | 'refuse'             // existing
  | 'forced-stop'        // existing
  | 'interrupted'        // existing (HITL)
  | 'tool-resumed'       // existing (HITL)
  | 'tool-denied'        // existing (HITL)
  | 'rule-matched'        // existing (HITL)
  | 'report_published'    // NEW (Phase 18 RPT-04) — emits ReportCard in chat
  | 'plan_change_requested' // NEW (Phase 18 D18-D4) — emits change-requested terminal state
  ;

// DecisionPayload — extends with ReportPublishedPayload
interface ReportPublishedPayload {
  title: string;       // e.g. "2026-08 业务月报"
  period: string;      // e.g. "2026-08"
  version: number;      // e.g. 1
  url: string;         // e.g. "/reports/2026-08/v1.html"
  versions?: string[]; // optional historical version URLs (D18-D3)
}

// TerminalApproval status — adds 'change_requested' (D18-D4)
type TerminalStatus = 'approved' | 'denied' | 'expired' | 'auto-passed' | 'failed' | 'change_requested';
```

**HTTP endpoints:**
- `POST /api/session/:id/approval/:approvalId { decision: 'request_change', reason: '...' }` → returns `{ status: 'ok' }` or 4xx/5xx. Triggers new plan confirm gate on BE.
