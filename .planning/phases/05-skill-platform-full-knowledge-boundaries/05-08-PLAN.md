  The `Chat<UIMessage>` class IS exported from @ai-sdk/react (index.d.ts:329). Import:
    import { Chat, useChat } from '@ai-sdk/react';

  The `useChat` hook signature (per index.d.ts): supports passing a pre-built
  `Chat` instance via the `chat` option. When `chat` is provided, the `id` prop
  MUST NOT also be passed — both being provided still triggers the
  shouldRecreateChat branch in dist/index.js:326-328. Pass either `chat` (the
  existing instance we own) OR `id` (a fresh Chat gets allocated keyed by id).

  The `Chat` constructor accepts `{ id, transport, messages?, ... }`. Setting
  `id` on the Chat itself (NOT as a useChat option) does NOT trigger recreation
  because the recreation check is on `options.id`, not on Chat.id. So per-session
  Chat instances each carry their own `id` field, and the useChat hook always
  points at the same Chat instance we keep in a useRef — switching sessions
  means swapping the `chat` prop to the previously-allocated Chat for that id.

  if (!s) return s;
