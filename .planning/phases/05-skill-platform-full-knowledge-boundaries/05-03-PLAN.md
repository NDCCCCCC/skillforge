<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /api/skills/events SSE -> Zustand store | Untrusted BE SSE channel; messages drive ReloadToast. |
| Topbar skill-manager -> /api/skills (POST) | The 全部重载 CTA triggers a rescan; BE fsnotify is the trust boundary per V12. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-11 | DoS | SSE EventSource reconnect storm | mitigate | sse-client uses exponential backoff (3s base, cap 30s). Hook unmounts on component unmount. Store is debounced (max one toast per skill per 1s). |
| T-5-12 | Spoofing | Toast claims a skill-reloaded event that did not actually happen | accept | Toast is informational. Actual Skill reload is BE-side per D5-08 + 05-01 atomic.Pointer. A spoofed toast cannot affect routing. |
| T-5-13 | Tampering | Routing trace scores rendered via dangerouslySetInnerHTML | mitigate | RoutingTracePart renders scores as plain text. Score value formatted via toFixed(2) then stringified. NEVER inject HTML. |
| T-5-14 | Info Disclosure | Per-skill status surfaces validation error in tooltip | mitigate | Validation error from BE LoadError hook is text. Render as text node. If error contains absolute filesystem path, strip to basename (defensive substring after last /). |
| T-5-15 | EoP | Click on 全部重载 triggers fsnotify rescan | accept | Rescan only re-reads files; V12 symlink guard + Validate re-run per 05-01. Cannot widen access. |
</threat_model>
