<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wizard NL input -> generated SKILL.md | NL interview answers are turned into a 7-field manifest. The generated content is operator-influenced but ultimately machine-produced; Validate is the trust gate. |
| Wizard Commit -> skillsDir filesystem | The user-chosen Skill name is constrained to a regex + EvalSymlinks + rooted check; the write is atomic + Validate re-runs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-16 | Tampering / EoP | Path traversal via wizard-supplied Skill name (e.g. `../../etc/skill`) | mitigate | Sanitize Skill name to ^[a-z0-9-]+$ at the very first gate; second gate EvalSymlinks + rooted-directory check (V12 reuse); third gate skill.Validate. Three gates. Test TestWizard_Commit_RejectsPathEscape. |
| T-5-17 | Spoofing | Prompt injection via wizard NL input -> malicious YAML frontmatter | mitigate | Generated SKILL.md is parsed as YAML; skill.Validate rejects unknown/invalid fields. The body is treated as data (never executed). The LLM is instructed to obey the 7-field schema; Validate is the structural enforcement. |
| T-5-18 | Tampering | Wizard output that fails the 7-field validator (D5-11 closed-loop break) | mitigate | Generate retries once on validation failure; second failure returns error to FE. Test TestWizard_Generate_RetriesOnValidationFailure asserts the retry. FE renders the error inline per UI-SPEC §SC-3. |
| T-5-19 | DoS | Wizard LLM call hangs (BGE-M3 style outage but for the wizard model) | mitigate | The LLM call is bounded by a context timeout (the existing request context). On timeout, the wizard endpoint returns 504 with a structured error; FE shows 向导生成失败：{error}。 |
| T-5-20 | Repudiation | Wizard commit succeeds but fsnotify does not fire (operator claims it didn't) | mitigate | The success toast Skill 已创建：{skillName}。已注册并热加载。 is fired ONLY after the atomic write completes AND the BE emits the skill-reloaded SSE message. Audit log records the commit + the resulting file path. |
</threat_model>
