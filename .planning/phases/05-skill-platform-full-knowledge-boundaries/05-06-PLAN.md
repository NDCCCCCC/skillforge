<objective>
Ship the two post-verdict annotation passes (SC-6 + SC-7). The counter-evidence pass is a structural trust boundary: 历史-tier chunks surface as ANNOTATION only, never as grounding (D5-13). The redline pass is a conditional LLM call on policy gaps (D5-14 — only when verdict flags a gap). Both compose with the existing 10-step VerdictPipeline (05-02) without touching the verdict's trust floor.

Purpose: SC-6 is the trust-moat line — it shows the user that the agent knows about contradicting evidence WITHOUT letting 历史 leak into the verdict's grounding path. SC-7 turns a "需补充" verdict into a constructive clause-level rewrite proposal. Together they make the agent's failures actionable instead of opaque.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Verdict grounding -> counter-evidence annotation | The single most load-bearing trust boundary in Phase 5 (D5-13). Counter-evidence 历史 chunks must NEVER reach the verdict's chunksByID map. Enforced structurally by function signature. |
| Redline LLM output -> FE renderer | The LLM-generated proposedRewrite + rationale are rendered as text. No HTML injection risk if rendered as text nodes. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-25 | Moat erosion | Counter-evidence 历史 chunks enter chunksByID | mitigate | Function signature: emitCounterEvidence takes (ctx, c, qvec) only. NO chunksByID parameter. TestCounterEvidence_NotGrounded asserts the map is empty after the pass. |
| T-5-26 | Cost blowup | Redline LLM call on every verdict | mitigate | emitRedline gate is the FIRST line of the function: if 合规 -> return nil BEFORE any LLM call. TestRedline_Conditional asserts ChatModel.Generate call count == 0 on 合规. |

| T-5-29 | Info Disclosure | Redline proposed_rewrite might echo back the original policy verbatim (no real rewrite) | accept | The LLM is advisory; the user reviews the rewrite before any action. The download/copy CTAs are explicit user actions. v1 does NOT write back to the authority doc. |
