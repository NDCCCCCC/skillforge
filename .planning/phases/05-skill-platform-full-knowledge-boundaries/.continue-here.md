# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: JS Number safety for `Entry.Version` — a reload bump must be visible to the JS polling client. The original `time.Now().UnixNano()` (~1.7e18 > 2^53) made `+1` reloads invisible (double ULP ≈ 512). Replaced with a per-process `atomic.Int64` counter from 1. The FE polling diff MUST treat `version` as a JS-safe integer and diff by `>`, not `===` against a float-shaped value.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Bumping Version on reload FAILURE | The keep-old contract (pinned by `TestRegistry_Reload_ValidationFailure_KeepsOld` + `_SymlinkEscape_Rejected`) requires Version AND manifest UNCHANGED on failure.
