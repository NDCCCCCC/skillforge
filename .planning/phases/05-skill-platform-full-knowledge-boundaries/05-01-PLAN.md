<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BE skillsDir -> Registry | Untrusted filesystem location; SKILL.md files are operator-authored but their content is treated as code by the agent (D5-13 trust moat relies on this). |
| SSE wire -> FE renderer | Wire chunks are emitted to the browser; new data-redline type and DecisionPayload extensions must not enable XSS or payload smuggling. |
| Embedder -> DescriptionVec | The embedder is in-process; its result is cached in memory. A buggy or compromised embedder could poison routing scores, but the impact is routing mis-selection (recoverable, no security boundary breach). |

| T-5-02 | Spoofing | Wire chunk smuggling via DecisionPayload fields | mitigate | DecisionPayload fields are additive + omitempty; existing wire consumers ignore unknown fields (backward-compatible). TS mirror uses optional fields. No risk of smuggling a new decision value to the FE without the TS union knowing — the drift alarm catches it. |
