**行为红线（55-UI-SPEC §Honesty / §Forbidden，执行 agent 逐条自检）**：server truth only（无乐观状态、无本地秒表）；无「全部重试」、无 cancel 控制、无 `window.confirm`（重试是单击）；失败明细表无重试入口（入口唯一：时间线步骤行）；非 error 步骤不渲染按钮；矩阵不可点；unknown ≠ blank；stale ≠ 废弃（待重跑）、dead ≠ 永久失败（确定性错误 — 不自动重试）。

**wire gap 记录（执行前核对，不擅补 BE）**：① `GET /api/admin/ingest/jobs`（列表）不在 54-01..05 交付内——执行时 read_first `internal/server/admin_ingest.go` 核对；不存在时 Jobs 视图按 §Component 8 渲染 `摄取任务加载失败（点击重试）` 错误行（诚实可见），**不得**降级为假空态「暂无摄取任务」（有 job 却显示无 = 说谎）；上传交接入口不受影响（走 `fetchJob(id)`，54-01 已交付）。② `docs[]`/`progress_msg`/`summary` 未下发前，矩阵不渲染、日志流空态、inspect 摘要区缺省——降级分支即 55-02 测试钉死的形态。

Output: 第 13 个 admin tab（摄取任务）全功能可用；上传后自动打开该 job 的流水线视图；`npx vitest run src/components/admin` 全绿（含 PipelineTab 回归计数 13）。
