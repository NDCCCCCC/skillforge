## Tasks (per-IN atomic)

### Task 1: IN-05 detached run goroutine panic recovery
- **File:** `internal/server/admin_pipeline.go:112-116`
- **Fix:** `defer recover()` at top of detached goroutine; log stack via `runtime/debug.Stack()`; on panic release running flag + reset stage to idle (复用 CR-01 fix `setStatus(StageIdle, ...)`)
- **Regression:** `TestAdminPipelineRunGoroutineRecoversFromPanic` — 在 detached goroutine 触发 panic（mock chat model）；assert (a) server 不 crash; (b) running flag re-claimable; (d) stage == idle
- **Commit:** `fix(42-02): IN-05 detached run goroutine panic recovery`

### Task 2: IN-02 section-cap sub-split
- **File:** `internal/knowledge/ecl/extract.go:148-176`
- **Fix:** 在 per-section path（line 156 附近）传入 `s.Body` 之前加 cap check；若超 cap 复用 `chunk.go::subSplit` 作 ≤4096 字节 chunks，迭代 LLM extraction
- **Regression:** `TestExtractOversizeSectionSubSplits` — 注入 93,993-byte section（per IN-02 RESEARCH 测得）；assert LLM 被调多次而非一次 oversized prompt
- **Commit:** `fix(42-02): IN-02 section-cap sub-split for oversize sections`

### Task 3: IN-04 ledger errors masquerade as 404
- **Files:** `internal/knowledge/ecl/manager.go:377-380` + `internal/server/admin_pipeline.go:159-161`
- **Fix:** 区分 `ErrNoFailureRecord` (404 + "unknown note") vs 其他 store errors (500 + generic msg); 500 时 server log 含 detail，HTTP body 仅 generic
- **Regression:** `TestRetryNoteHandlerDistinguishesStoreErrors` — mock FailureStore 返回 generic error; assert HTTP 500 + body 不含 internal error text；server log 含 detail
- **Commit:** `fix(42-02): IN-04 distinguish ledger store errors from not-found`

### Task 4: IN-07 watermark failure silences to 1 (PK-collision risk)
- **File:** `cmd/server/main.go:955-960`
- **Fix:** watermark error → skip arming manager（log reason）；admin 路由返回 503（已是 nil-posture）
- **Regression:** `TestBootSkipsECLManagerOnWatermarkFailure` — mock GetMaxIDCollection 返回 error；assert mgr 为 nil + admin route 503
- **Commit:** `fix(42-02): IN-07 boot skips ECL manager on watermark failure`

### Task 5: IN-01 buildExtractionPrompt dead code
- **File:** `internal/knowledge/ecl/extract.go:83-87`
- **Fix:** 删除 OR 路由 `ExtractNote` 的 under-cap path 通过它（选删除 — IN-07 的 `_` 后缀 = unused）
- **Regression:** `TestExtractUnderCap_DeletedOrShortened` — assert under-cap 仍走 joinSectionBodies + promptForBody；zero behavior change
- **Commit:** `fix(42-02): IN-01 remove dead code buildExtractionPrompt`

### Task 6: IN-03 batch milvus-load overstates attempt count
- **File:** `internal/knowledge/ecl/manager.go:351-355,519-521`
- **Fix:** 记录真实 attempt number（从 retry loop 取）for batch-terminal failures；更新 Failure.AttemptCount 字段语义文档（per-batch = batch budget exhausted）
- **Regression:** `TestBatchMilvusLoadRecordsRealAttempt` — force BuildDocuments failure first try；assert AttemptCount == 1（不是 maxAttempts=3）
- **Commit:** `fix(42-02): IN-03 batch milvus-load records real attempt`

### Task 8: IN-06 retry backoff ctx-aware
- **File:** `internal/knowledge/ecl/manager.go:461,485,516`
- **Fix:** 替换 `time.Sleep(m.backoffFor(attempt))` 为 `select { case <-ctx.Done(): return ctx.Err(); case <-time.After(d): }`；保留 loop 顶端的 ctx.Err() re-check
- **Regression:** `TestRetryBackoffRespectsCancellation` — cancel ctx during backoff; assert (a) backoff returns within <100ms; (b) loop 退出 not exhausted; (c) ctx.Err() propagated
- **Commit:** `fix(42-02): IN-06 retry backoff is ctx-aware`

### Task 9: IN-08 non-stable sort underpins pin
- **File:** `internal/knowledge/ecl/manager.go:317-321`
- **Fix:** `sort.Slice` → `sort.SliceStable`；非数字 SourceIdx skip（dead-letter not collide at 0）
- **Regression:** `TestManagerStableSortsDuplicateSourceIdx` — 注入 multiple 相同 SourceIdx；assert 排序稳定（kg 写顺序确定）
- **Commit:** `fix(42-02): IN-08 sort is stable + non-numeric SourceIdx dead-letters`

### Task 10: IN-09 ApplyNote replace not transactional
- **File:** `internal/knowledge/ecl/abox.go:109-150` + `internal/ontology/store/store.go:151-184`
- **Fix:** 不改 store-level locking（影响面过大）；document 当前 bounded impact（intermediate state 是 valid RG，下一次 run/retry converges）；如未来需要，route manual snapshots through store-level RLock + ApplyNote "in-flight" flag
- **Regression:** 不需新 test（document-only）；加 godoc comment 解释当前 contract
- **Commit:** `fix(42-02): IN-09 document ApplyNote bounded-impact contract`
