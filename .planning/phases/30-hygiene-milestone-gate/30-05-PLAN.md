WR-06 fix: FeedbackRow.tsx 第 170 行附近的 useState 种子改为 useEffect 同步。

将：
```tsx
const [locked, setLocked] = useState<Vote | null>(votedVerdict);
```

改为：
```tsx
// WR-06: useEffect syncs server truth (votedVerdict) to lock state,
// handling the case where data-turn arrives after initial mount.
const [localLock, setLocalLock] = useState<Vote | null>(null);
useEffect(() => {
    if (votedVerdict) {
        setLocked(votedVerdict);
    }
}, [votedVerdict]);
const locked = localLock ?? votedVerdict;
```

同时保留 optimistic lock 写入（POST 成功后 `setLocked(verdict)`）在 `handleVote` 函数中。

注意：
1. `setLocked` 调用不变（仍然写入 `locked` 状态）
2. `localLock ?? votedVerdict` 表示本地 optimistic 优先，否则 fallback 到 server truth
3. votedVerdict 为 null/undefined 时不覆盖已锁定的本地状态
