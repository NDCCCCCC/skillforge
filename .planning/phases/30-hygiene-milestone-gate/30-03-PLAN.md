  <action>
WR-03 fix: webhook.go 的 `http.Client` 构造（约第 93-96 行）添加 `CheckRedirect` 策略。

将现有的：
```go
client: &http.Client{
    Transport: http.DefaultTransport.(*http.Transport).Clone(),
},
```

改为：
```go
client: &http.Client{
    Transport: http.DefaultTransport.(*http.Transport).Clone(),
    CheckRedirect: func(req *http.Request, via []*http.Request) error {
        if len(via) >= 3 {
            return fmt.Errorf("ticket webhook: too many redirects")
        }
        if req.URL.Host != via[0].URL.Host {
            return fmt.Errorf("ticket webhook: refusing cross-host redirect to %s", req.URL.Host)
        }
        return nil
    },
},
```

注意：
1. `via` 参数是已访问的 redirect 链，`via[0]` 是第一个请求（即原始请求）
2. 第一个 redirect 触发时 `len(via) == 1`（已有 1 个请求），最多允许 2 次 redirect（len < 3）
3. 错误信息包含目标 host 用于审计
4. 不需要修改 `postOnce` 函数中的调用方式
