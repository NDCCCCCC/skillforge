# Plan 38-03: LLM Schema Induction + PascalCase IRI Generator

<read_first>
- .planning/phases/38-foundation-tbox-kg/38-CONTEXT.md (D-Induct-01..06 决策: 自然语言 + 自动 IRI + 双语 rdfs:label)
- .planning/spikes/005b-skillschema-rdfs-lift/main.go (TBox emitter Generate 函数复用)
- internal/llm/ 现有 LLM client 接口 (GenerateOption 模型调用方式)
- internal/store/sqlite/ (proposal 持久化复用)
- .planning/REQUIREMENTS.md 第 675 行 (ONT-04 LLM-driven schema induction)
</read_first>

<acceptance_criteria>
- `Proposal` struct: `{ID, Kind ("Class"|"ObjectProperty"|"DatatypeProperty"), DescriptionZH, DescriptionEN, LocalName (PascalCase), ProposedIRI (full IRI), ProposedTriples ([]string in TTL syntax), Status ("pending"|"approved"|"rejected"), SourceText, CreatedAt, ApprovedAt?}`
- `func Generate(ctx, llmClient, text string) (Proposal, error)`: 调用 LLM (复用 internal/llm.Client.Generate 接口), prompt schema 固定为 `{kind, description_zh, description_en}`, 解析后自动从 description_en 生成 PascalCase 本地名 (去除空格/特殊字符、首字母大写、冲突追加 N)
- `func Approve(ctx, store, emitter, proposalID string, customLocalName string) (Proposal, error)`: 
  - 若 customLocalName 非空则覆盖 PascalCase 默认
  - 调 PreviewIRI 检查冲突; 冲突返回 ErrIRIConflict
  - 调 emitter.Emit() 重生成当前 TBox TTL + 把 proposal 的 triples 拼接到 TTL 末尾
  - 写入 skillforge_tbox.v{N+1}.ttl + 更新软链 skillforge_tbox.ttl + tbox_version.txt 自增 1
  - Proposal.Status = "approved", ApprovedAt = now
- `func PreviewIRI(localName string) error`: 在现有 TBox TTL 中 grep `skf:{localName}` 前缀, 命中返回 ErrIRIConflict
- `TestGeneratePascalCase`: "business rule" → "BusinessRule"; "SQL Note" → "SQLNote"; "etl_table" → "EtlTable"
- `TestGenerateBilingualLabel`: proposal.ProposedTriples 含 `rdfs:label "中文描述"@zh , "English description"@en`
- `TestApproveIncrementsTBoxVersion`: 初始 v1, 一次 approve 后 v2, skillforge_tbox.v2.ttl 存在 + skillforge_tbox.ttl 软链指向 v2
- `TestPreviewIRIConflictDetection`: 用已存在的 "Skill" 作为 localName 调用 PreviewIRI 断言 ErrIRIConflict
- `TestLLMStub`: 用 stub Generate 函数 (不调真实 LLM) 验证 proposal 字段映射正确
- `go test ./internal/ontology/induction/ -v` 退出码 0
</acceptance_criteria>

<action>
1. 创建 `internal/ontology/induction/proposal.go`:
   - `type ProposalKind string` const `KindClass ProposalKind = "Class"` 等三种
   - `type ProposalStatus string` const `StatusPending / StatusApproved / StatusRejected`
   - `type Proposal struct { ID string; Kind ProposalKind; DescriptionZH, DescriptionEN string; LocalName string; ProposedIRI string; ProposedTriples []string; Status ProposalStatus; SourceText string; CreatedAt time.Time; ApprovedAt *time.Time }`
   - `func (p Proposal) Validate() error` 校验必填字段非空
2. 创建 `internal/ontology/induction/induction.go`:
   - `type Generator interface { Generate(ctx, prompt string, opts ...llm.GenerateOption) (string, error) }` 接受任何 LLM client (mock-friendly)
   - `func Generate(ctx, g Generator, text string) (Proposal, error)`:
     - 用 prompt template: `"Analyze the following text and propose an OWL/RDFS Class/Property... Output JSON {kind, description_zh, description_en}"`
     - 调 g.Generate
     - 解析 JSON, 从 description_en 用 `toPascalCase(s) string` 函数生成 localName (规则: trim spaces, 替换非字母数字为空, 按空格 split, 每个 word 首字母大写拼接; 若与已有 localName 冲突追加 "2", "3"...)
     - 构造 Proposal, ProposedTriples 包含: `skf:{localName} a skf:{Kind} ; rdfs:label "{zh}"@zh , "{en}"@en .`
     - 持久化到 SQLite (复用 internal/store/sqlite 写 proposals 表)
   - `func Approve(ctx, store, emitter *emitter.Emitter, proposalID string, customLocalName string) (Proposal, error)`:
     - 从 store 加载 proposal
     - 若 customLocalName 非空则覆盖 proposal.LocalName + ProposedIRI
     - 调 PreviewIRI; 冲突返回 ErrIRIConflict
     - 调 emitter.Emit() → 当前 TTL → append proposal triples → 写到 `skillforge_tbox.v{N+1}.ttl`
     - 更新软链 `skillforge_tbox.ttl` → `skillforge_tbox.v{N+1}.ttl` (用 os.Symlink; Windows 用 copy + delete fallback, 因 admin 权限可能限制 symlink)
     - 更新 `tbox_version.txt` 内容为 N+1
     - 把 proposal 插入 KG store (复用 Plan 38-02 的 store.Insert)
     - proposal.Status = "approved"; ApprovedAt = now
   - `func PreviewIRI(localName string) error`: 读取 skillforge_tbox.ttl 全文, 检查 `<http://skillforge.local/ontology#{localName}>` 或 `skf:{localName}` 是否存在
3. 创建 `internal/ontology/induction/induction_test.go`:
   - `TestGeneratePascalCase`: 表驱动测试覆盖 5 个用例
   - `TestGenerateBilingualLabel`: 用 stub generator 返回固定 JSON, 验证 Proposal.ProposedTriples 含双语 rdfs:label
   - `TestApproveIncrementsTBoxVersion`: tmp 目录初始化 v1, mock approve, 断言 v2 文件存在 + tbox_version.txt 内容 "2"
   - `TestPreviewIRIConflictDetection`: 用 "Skill" (已存在) 调 PreviewIRI, 断言 ErrIRIConflict
   - `TestLLMStub`: stub generator 返回 `{kind:"Class", description_zh:"业务规则", description_en:"business rule"}`, 验证 proposal.LocalName == "BusinessRule", ProposedTriples 包含 rdfs:label 双语
4. 验证: `go test ./internal/ontology/induction/ -v`
</action>
