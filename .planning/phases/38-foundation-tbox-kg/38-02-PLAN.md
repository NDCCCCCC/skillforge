<acceptance_criteria>
- `internal/ontology/store/store.go` 定义 `type Store struct` 含 `byS, byP, byO map[string][]int` + `all []Triple` 字段; `Triple{S, P, O string}` 可 JSON 序列化
- `NewStore() *Store` 初始化三个空 map
- `Insert(t Triple)` O(1) 插入, 三索引同步更新
- `Query(subj, pred, obj string) []Triple` 模式匹配; 空字符串通配; 按索引分桶后线性过滤
- `Adjacent1(subj, pred string) []string` 1-hop forward; 返回去重排序的 object 列表
- `Adjacent1Reverse(pred, obj string) []string` 1-hop reverse (新加, spike 未提供但 ONT-08 要求双向)
- `Adjacent2(subj, pred1, pred2 string) []string` 2-hop forward
- `Adjacent2Reverse(pred2, pred1, obj string) []string` 2-hop reverse
- `Snapshot() ([]byte, error)` 输出 JSON
- `LoadSnapshot(data []byte) (*Store, error)` 从 JSON 重建 Store
- `SnapshotDebounced(path string, delay time.Duration) func()` 返回一个 trigger 函数; 5s 内多次调用仅最后一次落盘
- `TestStoreLoad215Triples`: load 005b 的 skillforge_tbox.ttl 215 triples < 100ms
- `TestStoreQueryByType`: Query("", type, Skill) 返回 8 个 Skill 实例
- `TestStoreAdjacent1`: `cat_sql-guides -> belongsToTier -> [cat_sql-guides]`
- `TestStoreAdjacent1Reverse`: `belongsToTier <- cat_sql-guides` (cat_sql-guides 作为 object, 找所有 subject)
- `TestStoreSnapshotRoundtrip`: 215 → Snapshot → LoadSnapshot → 215 triples 字节级一致
- `TestStoreDebounceBehavior`: 100ms 内连续 Insert 10 次 + SnapshotDebounced(delay=5s), 断言 5s 后文件只写一次 (用 mock timer 或 time.Sleep 6s)
- `go test ./internal/ontology/store/ -v` 退出码 0
</acceptance_criteria>

<action>
1. 创建 `internal/ontology/store/store.go` (Apache-2.0 header, package store):
   - `type Triple struct { S, P, O string }` 三元组 (S/P/O 为 full IRI 字符串; O 可为 `"literal"^^xsd:decimal` 形式字符串)
   - `type Store struct { mu sync.RWMutex; all []Triple; byS, byP, byO map[string][]int }`
   - `func NewStore() *Store` 三 map 初始化
   - `func (s *Store) Insert(t Triple)` 写锁 + 三索引追加; O(1)
   - `func (s *Store) Query(subj, pred, obj string) []Triple` 读锁; 选最稀疏的索引作 candidates; 过滤剩余; nil = wildcard
   - `func (s *Store) Adjacent1(subj, pred string) []string` 调用 Query(subj, pred, "") 提取去重排序的 O
   - `func (s *Store) Adjacent1Reverse(pred, obj string) []string` Query("", pred, obj) 提取去重排序的 S
   - `func (s *Store) Adjacent2(subj, pred1, pred2 string) []string` Adjacent1 + 二跳
   - `func (s *Store) Adjacent2Reverse(pred2, pred1, obj string) []string` 反向二跳
   - `func (s *Store) Snapshot() ([]byte, error)` json.MarshalIndent(s.all, "", "  ")
   - `func LoadSnapshot(data []byte) (*Store, error)` 反序列化后遍历 Insert
   - `type debouncer struct { mu sync.Mutex; timer *time.Timer; path string; s *Store }` + `func (s *Store) SnapshotDebounced(path string, delay time.Duration) func()` 返回 trigger 函数: 每次调用 reset timer, timer 到期后调 Snapshot 写 path
2. 创建 `internal/ontology/store/store_test.go`:
   - `TestStoreLoad215Triples`: 用 `graph.NewGraph() + turtle.Parse` 加载 spike 005b 的 skillforge_tbox.ttl, 遍历 `g.Triples(nil, nil, nil)` 转 Triple 灌入 Store, 断言 `len(s.all) < 100ms`
   - `TestStoreQueryByType`: Query("", "http://www.w3.org/1999/02/22-rdf-syntax-ns#type", "http://skillforge.local/ontology#Skill") 断言 8
   - `TestStoreAdjacent1`: Adjacent1("http://skillforge.local/ontology#cat_sql-guides", "http://skillforge.local/ontology#belongsToTier")
   - `TestStoreAdjacent1Reverse`: Adjacent1Reverse("http://skillforge.local/ontology#belongsToTier", "http://skillforge.local/ontology#cat_sql-guides") 断言包含 1 个 cat
   - `TestStoreSnapshotRoundtrip`: Snapshot → LoadSnapshot → len 一致 + Query 结果一致
   - `TestStoreDebounceBehavior`: 临时目录 tmpfile, SnapshotDebounced(200ms 测试值), 100ms 内 Insert 10 次, 等 300ms 后检查文件存在且最后内容包含最后插入的 triple; 不允许写 10 次
3. 验证: `go test ./internal/ontology/store/ -v`
</action>
