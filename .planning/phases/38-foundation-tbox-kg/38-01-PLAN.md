<action>
1. 添加依赖: 运行 `go get github.com/tggo/goRDFlib@v0.1.0` 让 go.mod / go.sum 自动更新; 验证 go.mod 含 `require github.com/tggo/goRDFlib v0.1.0` 行
2. 创建目录: `internal/ontology/emitter/`
3. 创建 `internal/ontology/emitter/emitter.go` (Apache-2.0 header, package emitter):
   - 定义 package-level 常量: `DefaultNS = "http://skillforge.local/ontology#"`
   - 定义 `Skill` 结构体: `{Name, Description, Agent string; Reads, Writes []string; Temperature float64; Prohibitions, RefusalPhrases []string}` (从 SKILL.md YAML frontmatter 解析)
   - 定义 `KBCategory` 结构体: `{TierName string; SubCategories []string}`
   - 定义 `Emit(skillsRoot, kbRoot, ns string) (string, error)` 主函数:
     - 遍历 `skillsRoot` 下所有子目录, 读 `SKILL.md` (用 `gopkg.in/yaml.v3` 解 7 字段 frontmatter, 已有依赖可复用)
     - 遍历 `kbRoot` 下所有一级目录作为 tier (authority / draft / historical / personal / sql-guides), 遍历 sql-guides 下二级目录作为 sub-categories (其他 等)
     - 用字符串拼接生成 TTL 内容, 输出前缀 `@prefix skf: <{ns}> .` `@prefix owl: <http://www.w3.org/2002/07/owl#> .` `@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .` `@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .`
     - 声明 6 owl:Class (Tier / KBCategory / SubCategory / Skill / SkillAgent / RefusalPhrase) + 6 owl:ObjectProperty (belongsToTier / hasSubCategory / hasReadAccess / hasWriteAccess / poweredBy / requiresRefusal) + 8 owl:DatatypeProperty (skillName / skillDescription / skillTemperature / categoryName / subCategoryName / tierName / agentTypeName / refusalPhraseText)
     - 对每个 Skill 生成个体: `<{ns}skill_{Name}> a skf:Skill ; skf:skillName "Name" ; skf:skillDescription "..." ; skf:poweredBy <{ns}agent_{AgentType}> ; skf:skillTemperature "0.0"^^xsd:decimal .` ; 对 reads[] 中形如 `tier/**` 的项生成 `skf:hasReadAccess <{ns}cat_{tier}>` 关系
     - 对每个 Tier 生成 `<{ns}cat_{tier}> a skf:KBCategory ; skf:categoryName "tier" .` ; 对 sql-guides 的 7 个子目录生成 `<{ns}subcat_{chineseName}> a skf:SubCategory ; skf:subCategoryName "中文名" ; skf:belongsToTier <{ns}cat_sql-guides> .`
   - 函数签名: `func Emit(skillsRoot, kbRoot, ns string) (string, error)` 返回 TTL 字符串
   - CJK 子目录名保持 verbatim (Turtle 允许; spike 005b 验证过)
4. 创建 `internal/ontology/emitter/emitter_test.go`:
   - `TestEmitSkillInstanceCount`: 调用 Emit(项目根的 skills/ + knowledge/, DefaultNS), 用 `graph.NewGraph() + turtle.Parse` 加载, 查询 `?x a skf:Skill` (full IRI `http://www.w3.org/1999/02/22-rdf-syntax-ns#type` 作为 predicate, `http://skillforge.local/ontology#Skill` 作为 object), 断言 `len(skills) == 8`
   - `TestEmitTierInstanceCount`: 同上, 查询 `?x a skf:KBCategory`, 断言 `len == 5`
   - `TestEmitSubCategoryInstanceCount`: 查询 `?x a skf:SubCategory`, 断言 `len == 7`
   - `TestEmitRoundtrip`: emit → turtle.Parse → turtle.Serialize → turtle.Parse 再次加载, 断言 `g.Len() == first_g.Len()`
   - `TestEmitNamespaceOverride`: 用 `https://override.example/#` 调用 Emit, 查询某个 IRI 断言新前缀生效
5. 验证: `cd /path/to/ai-agent && go mod tidy && go build ./... && go test ./internal/ontology/emitter/ -v`
</action>
