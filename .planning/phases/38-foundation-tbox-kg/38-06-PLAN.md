  - `test_sc1_boot_generates_tbox`: 启动 cmd/server, 等 3s, 检查 `data/ontology/skillforge_tbox.ttl` 存在 + 长度 > 10000 bytes; `data/ontology/skillforge_tbox.v1.ttl` 存在; `data/ontology/tbox_version.txt` 内容 "1"

  - `test_sc3_no_cgo`: `go build -tags !cgo ./cmd/server` 成功 (实际 go.mod 无 cgo 依赖; 验证方式: `go list -deps ./cmd/server | grep -E "librdf|redland"` 应为空)
  - `test_sc4_admin_ui_lists_8_skills`: curl GET /api/admin/ontology/kg/query 配合 type=Skill 过滤; 或 GET /api/admin/ontology/tbox + grep "skill_compliance" 等 8 个; 断言至少 8 个 Skill 实例
  - `test_sc5_kg_pattern_query`: curl GET /api/admin/ontology/kg/query?p=...&o=... (s=p= 空); 断言响应 matches 数组 ≥ 8
  - `test_sc6_llm_propose_approve_loop`: 
    - POST /api/admin/ontology/proposals/generate body {text:"a new business rule for compliance"} → 200 + proposal.id
    - POST /api/admin/ontology/proposals/:id/approve body {custom_local_name:"BusinessRule"} → 200 + tbox_version=2
    - 检查 `data/ontology/skillforge_tbox.v2.ttl` 存在 + `tbox_version.txt` 内容 "2"
  - `test_sc7_tbox_rollback`: 当前 v2, 调用模拟 rollback (Phase 38 暂未实现 POST /api/admin/ontology/tbox/rollback; smoke 验证: 手动 cp skillforge_tbox.v1.ttl 到 skillforge_tbox.ttl + 验证重新加载后 triple count 不变); Phase 40 完整实现
  - `test_sc8_verify_all_green`: 跑完上述 7 个 test + 集成 "go build ./... + go test ./internal/ontology/... + go test ./internal/server/ -run TestAdminOntology" 全绿
- 每个 test 输出 `[PASS] test_sc{N}` 或 `[FAIL] test_sc{N}` + diagnostics
- main 函数: cleanup() trap kill server; run_all_tests; exit 0 if all PASS
- `bash scripts/verify-phase-38.sh` 退出码 0
- 运行时间 < 60s (含 build + server boot + curl)
</acceptance_criteria>
