<acceptance_criteria>
- `internal/server/admin_ontology.go` 定义 8 个 handler:
  - `func (s *Deps) adminOntologyTBoxHandler(ctx, c)`: GET /api/admin/ontology/tbox → 200 {version, triple_count, ttl}; 403 if no admin token
  - `func (s *Deps) adminOntologyKGStatsHandler(ctx, c)`: GET /api/admin/ontology/kg/stats → 200 {triple_count, byS_size, byP_size, byO_size, memory_kb_estimate}
  - `func (s *Deps) adminOntologyKGQueryHandler(ctx, c)`: GET /api/admin/ontology/kg/query?s=&p=&o= → 200 {matches: [{s,p,o}, ...]}; 空 query param = 通配
  - `func (s *Deps) adminOntologyProposalsGenerateHandler(ctx, c)`: POST /api/admin/ontology/proposals/generate body {text} → 200 {proposal}; 调 induction.Generate
  - `func (s *Deps) adminOntologyProposalsListHandler(ctx, c)`: GET /api/admin/ontology/proposals → 200 {proposals: [...]}
  - `func (s *Deps) adminOntologyProposalsApproveHandler(ctx, c)`: POST /api/admin/ontology/proposals/:id/approve body {custom_local_name?} → 200 {proposal, tbox_version}; 调 induction.Approve
  - `func (s *Deps) adminOntologyProposalsRejectHandler(ctx, c)`: POST /api/admin/ontology/proposals/:id/reject → 200 {proposal}
  - `func (s *Deps) adminOntologySnapshotHandler(ctx, c)`: POST /api/admin/ontology/snapshot → 200 {path, triple_count}; 手动触发
- 每个 handler ≤ 200 行; 全部先 `requireAdmin(c)` 门控
- `internal/server/server.go` route 注册段插入 8 个 h.GET/h.POST
- `internal/server/deps.go` 新增 `OntologyDep struct { Emitter *emitter.Emitter; Store *store.Store; Induction *induction.Generator; TBoxVersion int }` 字段
- `cmd/server/main.go` boot 段插入:
  - `emitter := ontology.NewEmitter(skillsRoot, kbRoot, ns)`
  - `kgStore, err := store.LoadSnapshot(snapshotPath)`; 若失败用空 store
  - 重生成 TTL + 灌入 kgStore (215 triples)
  - `kgStore.SnapshotDebounced(snapshotPath, 5*time.Second)`
  - `gen := induction.NewGenerator(llmClient)` (复用现有 LLM client)
  - 注入到 `deps.OntologyDep`
- `TestAdminOntologyRequiresToken`: 8 个端点全部 403 when X-Admin-Token 缺失或错误
- `TestTBoxEndpoint`: GET /api/admin/ontology/tbox with valid token → version=1, triple_count=215, ttl 长度 > 10000 bytes
- `TestKGQueryEndpoint`: GET /api/admin/ontology/kg/query?p=...&o=... → 8 个 Skill matches
- `TestProposalApproveFlow`: stub LLM → POST generate → POST approve → GET tbox version=2
- `go build ./cmd/server` 退出码 0
- `go test ./internal/server/ -run TestAdminOntology` 退出码 0
</acceptance_criteria>

<action>
1. 创建 `internal/server/admin_ontology.go`:
   - 文件头 Apache-2.0 + package server
   - 定义 response envelope: `type tBoxResponse struct { Version int; TripleCount int; TTL string }`; `type kgStatsResponse struct {...}`; `type kgQueryResponse struct { Matches []store.Triple }`; `type proposalResponse struct { Proposal induction.Proposal; TBoxVersion int }`
   - 8 个 handler 函数, 每个都用 `if !requireAdmin(c) { return }` 门控, 用 `c.JSON(consts.StatusOK, ...)` 返回
   - handler 内部逻辑尽量委托给 emitter / store / induction 包; handler 只做参数解析 + 错误转 HTTP code
   - 注意 HTTP 路由参数解析: c.Param("id") 取 proposal ID
2. 修改 `internal/server/deps.go`:
   - import `github.com/skillforge/skillforge/internal/ontology/emitter` + `internal/ontology/store` + `internal/ontology/induction`
   - 在 Deps struct 添加 `OntologyDep struct { Emitter *emitter.Emitter; Store *store.Store; Induction *induction.Generator; TBoxVersion int }` (引用类型)
3. 修改 `internal/server/server.go` 第 569-640 行 route 注册段, 在 `h.GET("/api/admin/skills", ...)` 后插入 8 个新路由
4. 修改 `cmd/server/main.go`:
   - 在 `func main()` 早期 (buildRunner 之前) 初始化 ontology 组件
   - 用 envOr("SKILLFORGE_ONTOLOGY_NS", emitter.DefaultNS) 拿 ns
   - 用 envOr("SKILLFORGE_ONTOLOGY_DATA_DIR", filepath.Join(projectRoot, "data", "ontology")) 拿 dataDir
   - 用 envOr("SKILLFORGE_SKILLS_DIR", "skills") + envOr("SKILLFORGE_KB_DIR", "knowledge") 拿 skillsRoot/kbRoot
   - 创建 emitter, kgStore, induction, 注入 Deps
   - 加日志输出: `log.Printf("[INFO] cmd/server: ontology initialized (TBox v%d, %d triples, snapshot %s)", version, n, snapshotPath)`
5. 创建 `internal/server/admin_ontology_test.go`:
   - 用 `httptest` + hertz `app.New()` 构造 mini server
   - 4 个测试覆盖 acceptance criteria
6. 验证: `go build ./cmd/server && go test ./internal/server/ -run TestAdminOntology -v`
</action>
