## One-Liner

Wave 3 ships the full three-panel draggable layout with localStorage persistence (LeftSidebar skeleton + CenterPanel + RightChat), wires `SkillPicker` to select a Skill from the `skills.json` fixture and scope subsequent queries (SYSK-03, FEUI-04), replaces the Wave 2 `ChunkSourceView` placeholder body with real chunk verbatim from a `chunk-lookup.ts` helper driven by `chunks.json` (FEUI-03, KNOW-05), integrates `DataSubprogressPart` (FEUI-06), wires `ChatInput` (composer with file-attach stub), writes the `transport-swap.test.ts` proving Mock and Default transports produce identical message parts (D-04 invariant), and replaces the spike-stub `citations.test.tsx` with one that uses the real chunk-lookup helper. Plan ends with a `checkpoint:human-verify` so the user can interactively verify the three-panel drag-resize behavior.

## Context

Wave 2 shipped VerdictCard + RefusalCard + ReasoningPart + TierBadge + CenterPanel + CitationCluster + locked-file reconciliation (Tailwind v4 + fontsource + @/* alias active).
