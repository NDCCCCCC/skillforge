# Phase 4 Plan 02 — Wave 2: VerdictCard + RefusalCard + ReasoningPreview + CenterPanel + Locked-File Reconciliation

## One-Liner

Wave 2 materializes the visual trust contract: `VerdictCard` (D-06 status-colored header + confidence bar + review-required badge), `RefusalCard` (D-07 out-of-scope blue-gray vs I-don't-know gray), `ReasoningPart` (D-08 progressive-disclosure preview), `TierBadge` (`[权威]` / `[历史]` / `[个人]` / `[草稿]`), `CenterPanel` (D-02 tabs: verdict / chunk-source / SKILL.md), `CitationCluster`, and reconciles the 4 locked root files (`package.json`, `tsconfig.json`, `vite.config.ts`, `web/src/main.tsx`) so `theme.css` activates via `@tailwindcss/vite` and fontsource variables load.

## Context

Wave 1 (`04-01`) shipped the parts dispatcher + fixtures + MockChatTransport + sanitize-url gate, but deliberately left the DataPolicyPart as a JSON-serializing placeholder (`web/src/components/chat/parts/DataPolicyPart.tsx`) because VerdictCard/RefusalCard are Wave 2 deliverables. The ReasoningPart is currently a `<details>` placeholder inside `MessageBubble.tsx` (`ReasoningPartPlaceholder`) which violates D-08 (it can push the answer off-screen under 1000+ token reasoning chains from GLM-5.2). The left/center/right panels in `App.tsx` are empty divs; CenterPanel is a JSON.stringify dump of the store. The 4 root config files were intentionally NOT modified in Wave 1 (locked-files constraint) so `theme.css` does not yet compile via `@tailwindcss/vite`, fontsource variables do not load, and there is no `@/*` path alias.

Wave 2 ships the real visual components, replaces the placeholders, wires CenterPanel + CitationCluster into the bubble, mounts CenterPanel in `App.tsx`, and reconciles the locked files so the design tokens actually render. Phase 2 backend is not required (mock transport + fixtures are the entire UI test surface).

Locked decisions honored: **D-01** (citation click → center panel), **D-02** (center defaults to verdict card; tab switches chunk-source / SKILL.md), **D-06** (verdict card visual), **D-07** (refusal card distinction), **D-08** (reasoning progressive disclosure above answer), **T-1-08** (sanitization already in Wave 1 — do not regress). Locked skill scope: P4 uses mock fixtures only; chunk-source/SKILL.md preview render from in-memory mock data (no backend).
