```go
package document

// MIME-to-parser registry. Format name == magic-byte verified MIME string.
type ParserRegistry struct {
    parsers map[string]Parser
    mu      sync.RWMutex
}

type Parser interface {
    // Parse reads from r and returns the plain-text content.
    // Password-protected files return ErrPasswordProtected.
    // Parsers MUST accept io.Reader (not *os.File).
    Parse(ctx context.Context, r io.Reader, filename string) ([]byte, error)
    // Name returns the parser identifier, e.g. "eino-ext/pdf@v0.1.13"
    Name() string
}

// ParseResult is the output of a successful parse.
type ParseResult struct {
    Content   []byte  // plain-text body
    Frontmatter []byte // YAML block if present, nil otherwise
    ParserName string  // which parser produced this
}

// ErrPasswordProtected is returned for protected binary docs.
var ErrPasswordProtected = errors.New("document: file is password-protected")

// ErrUnknownFormat is returned when no parser is registered for the MIME type.
var ErrUnknownFormat = errors.New("document: unknown format")

// NewParserRegistry returns a registry with all supported formats registered.
// The allowlist is the canonical list — no format is accepted unless registered.
func NewParserRegistry() *ParserRegistry { ... }

// Register records parser for mimeType. Called inside NewParserRegistry.
func (r *ParserRegistry) Register(mimeType string, p Parser)

// Parse uses the registered parser for mimeType to produce a ParseResult.
// Returns ErrUnknownFormat if mimeType is not registered.
func (r *ParserRegistry) Parse(ctx context.Context, mimeType string, rdr io.Reader, filename string) (*ParseResult, error)

// AllowedMIMETypes returns the whitelist of registered MIME types.
func (r *ParserRegistry) AllowedMIMETypes() []string
```

Register these five formats (MIME type → parser):
  1. "text/markdown" → goldmarkParser (wraps goldmark.YAML block strip)
  2. "application/pdf" → einoPDFParser (or pure-Go fallback)
  3. "application/vnd.openxmlformats-officedocument.wordprocessingml.document" → einoDOCXParser (or pure-Go fallback)
  4. "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" → excelizeParser
  5. "application/vnd.openxmlformats-officedocument.presentationml.presentation" → einoPPTXParser (or pure-Go fallback)

For md: use goldmark directly. Extract YAML frontmatter with the same bytes.HasPrefix(raw,[]byte("---\n")) pattern as indexer.go:splitFrontmatter.

For xlsx: use excelize to read each sheet as "col1: val1 | col2: val2 | ..." per row. Concatenate all sheets with "\n---\n" separator.

For pdf/docx/pptx: use the eino-ext parser if available (check with go list -m); if CGO or unavailable, use the pure-Go fallback.

For each binary format, check magic bytes first (PDF: %PDF; DOCX: PK...\docx; XLSX: PK...\xlsx; PPTX: PK...\pptx). If magic bytes mismatch the declared Content-Type → return error "content type does not match file signature".

Parser Name() strings use the form "eino-ext/pdf@v0.1.13" or "pure-go/excelize@v2" so the audit row records which library was used.

<pitfalls>
## Pitfalls to Avoid

**No hardcoded format list in handler code.** The Content-Type allowlist lives exclusively in ParserRegistry. The upload handler calls `registry.Parse(ctx, mimeType, rdr, filename)` and never branches on format name.

**Do not use `c.Request.FormFile` or `c.MultipartForm`.** These materialize parts to disk. Use the `multipart.NewReader(c.Request.BodyStream(), boundary)` pattern from import_api.go:325.

**Parser must accept io.Reader, not *os.File.** The upload handler passes a `bytes.Buffer` reader. A parser that only accepts `*os.File` will fail to integrate.

**CGO detection.** If the eino-ext PDF/DOCX parser surfaces CGO, add a `//go:build !cgo` tag for the pure-Go fallback path, and document the WSL-only constraint in the plan frontmatter.
</pitfalls>
