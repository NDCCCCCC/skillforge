```go
const (
    uploadMaxBodyDefault = 100 * 1024 * 1024 // 100 MB
    actionDocUploaded         = "action_doc_uploaded"
    actionDocUploadRejected   = "action_doc_upload_rejected"

// DocUploadAudit is the FrozenArgs payload for action_doc_uploaded.
type DocUploadAudit struct {
    Slug          string `json:"slug"`
    FileName      string `json:"file_name"`
    FileSize      int64  `json:"file_size"`
    SHA256        string `json:"sha256"`
    ParserVersion string `json:"parser_version"`
    ChunkCount    int    `json:"chunk_count"`
    IDRangeStart  int64  `json:"id_range_start"`
    IDRangeEnd    int64  `json:"id_range_end"`
}

// DocUploadRejectAudit is the FrozenArgs for action_doc_upload_rejected.
type DocUploadRejectAudit struct {
    Slug     string `json:"slug"`
    FileName string `json:"file_name"`
    FileSize int64  `json:"file_size"`
    Reason   string `json:"reason"`
}
```

**uploadHandler** (serves POST /api/admin/kb/:slug/upload):
1. **Admin token gate** — `isAdminRequest(c)` first; 403 on failure (CHECK ORDER: 403 before 503).
2. **KB registry nil check** — 503 if s.KBRegistry == nil.
3. **Slug param** — c.Param("slug"); validate via kb.ValidateSlug; 400 on failure.
4. **Slug active check** — reg.Lookup(slug) must return non-nil; deactivated/unknown → 404.
5. **Content-Length guard** — If Content-Length > UploadMaxBodyBytes → 413 with body "file too large: max {N} bytes". This fires BEFORE reading the body.
6. **Parse multipart** — Call parseUploadForm(c, onFile). Inside onFile:
   a. Read all bytes into `data := io.NopCloser(io.TeeReader(part, sha256Hash))`. Actually simpler: read into bytes.Buffer, then hash.
   b. Compute sha256 := fmt.Sprintf("%x", sha256.Sum256()) on the buffer.
   c. **Magic byte check** — call `VerifyMagicBytes(data, mimeType)`. If mismatch → 400 "content type does not match file signature".
   d. Call `UploadIndex(ctx, slug, data, mimeType, filename, s.Embedder, s.KBRegistry, nil)` (audit hook set at boot).
   e. If UploadIndex returns error → write action_doc_upload_rejected audit row → return 422 with error text.
   f. Call `s.IndexerBackend.Insert(ctx, docs)` (IndexerBackend is wired in Deps).
   g. Compute id_range_start = docs[0].ID, id_range_end = docs[len(docs)-1].ID.
   h. Write action_doc_uploaded audit row with DocUploadAudit struct.
   i. Return 200 with JSON: `{"chunks": len(docs), "id_range": [id_range_start, id_range_end]}`.

**parseUploadForm** — adapted verbatim from parseImportForm (import_api.go:325-398):

**Magic bytes table (DOC-03):**
- "%PDF" (4 bytes) → "application/pdf"
- "PK\x03\x04" (4 bytes) — ZIP local header; for docx/xlsx/pptx, also check the filename inside the ZIP
- "text/markdown" → check first line starts with "#" or "---"

<pitfalls>
## Pitfalls to Avoid

**CHECK ORDER: admin gate FIRST.** 403 must not leak whether KB registry is wired. This is the same invariant as kb_admin.go and must be replicated verbatim.

**Content-Length check BEFORE reading body.** Read the Content-Length header before activating the multipart reader. If Content-Length > limit, return 413 immediately — never start reading the stream.

**No FormFile or MultipartForm.** Use multipart.NewReader over BodyStream, same as parseImportForm. Those helpers materialize to disk.

**Audit hook fires AFTER Insert succeeds.** If Insert fails, the upload fails and the audit row is action_doc_upload_rejected. Only action_doc_uploaded on success.

**SHA-256 is computed on the in-memory buffer, never on disk.** bytes.Buffer stays in memory; hash.SHA256() computes on the buffer bytes.
</pitfalls>
