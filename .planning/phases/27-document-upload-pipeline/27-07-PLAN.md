```go
func isBackendUnavailable(err error) bool {
    if err == nil { return false }
    // Check for common connection errors
    msg := err.Error()
    return strings.Contains(msg, "connection refused") ||
           strings.Contains(msg, "context deadline exceeded") ||
           strings.Contains(msg, "no such host")
}
```

<pitfalls>
## Pitfalls to Avoid

**503 on backend down, not 500.** A 500 suggests the server is broken. A 503 with Retry-After tells the client "try again later" — this is the correct status for a transient backend unavailability.

**Audit row on ALL failure paths.** Every rejection writes action_doc_upload_rejected with the reason. The audit trail is complete regardless of how the upload failed.

**Deduplication is per slug + SHA-256.** The same file uploaded to two different slugs is NOT a duplicate — it's the same content in two different knowledge bases. The dedup check is `slug + sha256`.

**Partial audit row on parser error.** The action_doc_upload_rejected audit row is written with the SHA-256 (if computed) and the reason. The audit trail shows what was attempted even if the parse failed.
</pitfalls>
