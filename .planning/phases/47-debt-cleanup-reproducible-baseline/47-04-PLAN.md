<objective>
Close the frontend half of REL-02: after a rollback, refetch the cached SHACL report so the governance banner stops showing the boot-time report and the `trigger === 'rollback'` branch becomes reachable.

Purpose: `TimelineView.handleRollback` comments "Refetch all three surfaces" but only calls `fetchChangelog`. `GovernanceTab` fetches the report once on mount and switching the local `view` state does not remount it, so with the domain-layer write from 47-02 in place the fresh report would still never reach the banner. SC-2 requires both halves.

Output: an optional callback prop on `TimelineView`, one shared refetch handler in `GovernanceTab`, and a new component test.
</objective>
