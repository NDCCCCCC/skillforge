<objective>
Make the governance SHACL cache reflect rollback: write the report `RollbackTBox` already computes into the store cache, and correct the read-path comments so they describe the two real writers.

Purpose: `SetShaclReport` has exactly one call site today (`cmd/server/main.go:947`, boot). `RollbackTBox` at `induction.go:468` already runs `ValidateWithTrigger(..., "rollback")` but consumes only `ErrorCount` and discards the report, so after a rollback the admin surface keeps serving the boot report and `GovernanceTab`'s `trigger === 'rollback'` branch is unreachable. The fix reuses that already-computed report at zero extra cost and inside the same critical section as the version/pointer/TTL mutations.

Output: a rollback path that leaves the cache consistent with what it just validated; documentation that no longer overpromises.
</objective>
