# Integration design

The scheduler's report_job.go runs on a per-(skill, period) trigger. To produce a real report:

1. Load the Skill's ReportTemplate from the manifest
2. Call KPI executor to get current KPI values (all KPIs → MapSnapshot)
3. Call report.Render to produce HTML (needs template + slot texts)
4. Call report.Publish to write vN.html and get the URL
5. Store output_url in report_runs row

For step 3 (slot filling), the DeepAgent fills slot texts. For the scheduler, since this is automated, we can use a minimal/default slot text generation or call the DeepAgent path. The simplest approach: call report.Publish with empty SlotTexts ("" for each slot) to produce a report with KPI values rendered via the DefaultValueFormatter.

Key question: where does the ReportTemplate come from? The Skill manifest has a `Template` field (any type, map[string]any from YAML). We need to:
1. Load the skill's manifest (by name)
2. Get the Template from the manifest
3. Parse it via report.ParseTemplate into *ReportTemplate
4. Use it in Publish

The scheduler has access to the loader and store. We need to pass the registry/executor to RunReportJob.

```go
// GetAllKPISnapshots returns current values for all registered KPIs as a map.
// Used by the scheduler to capture KPI snapshots before report generation.
func (e *Executor) GetAllKPISnapshots(ctx context.Context) (map[string]any, error) {
    if e == nil || e.reg == nil {
        return nil, fmt.Errorf("executor not wired")
    }
    snapshots := make(map[string]any)
    for _, kpi := range e.reg.Catalog() {
        // Call with nil params to get current value
        val, err := e.Call(ctx, KPIFuncCall{Name: kpi.Name, Params: nil})
        if err != nil {
            // Log and continue — individual KPI failure shouldn't block all snapshots
            log.Printf("[WARN] scheduler: KPI %s snapshot failed: %v", kpi.Name, err)
            continue
        }
        snapshots[kpi.Name] = val
    }
    return snapshots, nil
}
```

The key insight: KPIFuncCall.Call with nil params should return the current value without filtering. Check the existing Call method — if it requires params, we may need to add a separate method or handle nil params gracefully.

The KPI registry catalog is accessed via `e.reg.Catalog()` which returns the list of KPI definitions. Each KPI has a `Name` field.

```go
// executeReportRun generates the report for skill/period and returns KPI snapshots + URL.
func executeReportRun(ctx context.Context, skillID, period string, kpiExec *kpi.Executor, storeDB store.Store, loader *skill.Loader) (map[string]any, string, error) {
    // 1. Get KPI snapshots
    var snapshots map[string]any
    if kpiExec != nil {
        var err error
        snapshots, err = kpiExec.GetAllKPISnapshots(ctx)
        if err != nil {
            log.Printf("[WARN] scheduler: GetAllKPISnapshots failed: %v", err)
            snapshots = make(map[string]any)
        }
    }

    // 2. Load skill manifest to get ReportTemplate
    var tmpl *report.ReportTemplate
    var approvalAuditID string
    if loader != nil {
        for _, m := range loader.Skills() {
            if m.Name == skillID {
                if m.Template != nil {
                    var err error
                    tmpl, err = report.ParseTemplate(m.Template)
                    if err != nil {
                        log.Printf("[WARN] scheduler: ParseTemplate for %s failed: %v", skillID, err)
                    }
                }
                break
            }
        }
    }

    // 3. If no template, generate minimal report
    if tmpl == nil {
        // Create a minimal template for automated runs
        tmpl = &report.ReportTemplate{
            Title:   skillID + " Report",
            Slots:   []report.SlotDef{},
            KPIs:    []string{},
            Version: "1",
        }
    }

    // 4. Build slot texts (empty for automated runs — KPI values via DefaultValueFormatter)
    slotTexts := report.SlotTexts{}
    for _, slot := range tmpl.Slots {
        slotTexts[slot.Name] = ""
    }

    // 5. Build snapshot for rendering
    snap := report.MapSnapshot(snapshots)

    // 6. Publish the report
    // approvalAuditID is empty for automated runs (no HITL approval)
    result, err := report.Publish(ctx, tmpl, slotTexts, period, snap, "", nil, skillID, nil)
    if err != nil {
        return snapshots, "", fmt.Errorf("report.Publish: %w", err)
    }

    return snapshots, result.URL, nil
}
```
