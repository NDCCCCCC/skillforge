    导出两个常量：`DistDirDefault = "web/dist"`（相对仓库根的 Vite 构建产物目录，依据 `web/vite.config.ts` 的默认 outDir 与 `Dockerfile.frontend:23-29`）与 `CatchAllPath = "/*filepath"`（hertz 根 catch-all 路由字面量；注释写明为什么不是 `/*`：`route/tree.go:115-148` 的 checkPathValid 要求 wildcard 带名字，`/*` 会在注册时 panic）。

    导出 `func Handler(distDir string) http.Handler`，返回一个 `http.HandlerFunc`，每个请求按以下顺序处理（注释逐条对齐 nginx 语义）：
    - 取 `p := r.URL.Path`，为空时按 `/` 处理。**先做 `/api` 前缀闸**：`p == "/api"` 或 `strings.HasPrefix(p, "/api/")` 时 `http.NotFound(w, r)` 并 return。注释写明这不是冗余：hertz 路由树是 static > param > any 优先级，已注册的 `/api/chat` 会命中静态节点，但**未注册**的 `/api/xxx` 在静态匹配失败后会 backtrack 到 anyChild（`route/tree.go:353`），因此 handler 内的这道闸是“未实现接口不得伪装成前端路由”的唯一保证。
    - 计算 `rel := path.Clean("/" + p)`（以 `/` 开头的已清洗路径，`/../x` 会被折叠成 `/x`），再 `fsPath := filepath.Join(distDir, filepath.FromSlash(rel))`。`filepath.Join` 自带清洗，且 rel 锚定在根，拼接结果不可能越出 distDir。
    - 用 `os.Lstat(fsPath)` 取文件信息：**用 Lstat 而非 Stat**，`info.Mode()&os.ModeSymlink != 0` 时按“文件不存在”处理（404 或 SPA fallback），拒绝通过 dist 内符号链接逃逸到仓库其它目录。注释同时记下残余风险：`http.FileServer` 之后会按路径重新打开文件（存在 TOCTOU 窗口），本包按“dist 是构建产物、非用户可写目录”接受该风险。
    - Lstat 失败时：`filepath.Ext(rel) == ""` ⇒ SPA fallback（`http.ServeFile(w, r, filepath.Join(distDir, "index.html"))`，先设 `Cache-Control: no-cache`）；有扩展名 ⇒ `http.NotFound(w, r)`，**绝不**回 index.html。
