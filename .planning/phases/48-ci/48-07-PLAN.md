**IN-05 — hermeticity is the union, not the job map.** In the P2 probe, build `keys = set((j.get("env") or {}).keys())` plus the keys of every `(s.get("env") or {})` in `steps`; fail unless that union is exactly `{"CGO_ENABLED"}`, naming the extra keys. **IN-04 — anchor the count literal.** Replace `for literal in ("666", "689", "84 ")` with two anchored checks over the file text.

(a) A **tight-gap** count-phrase regex, case-insensitive: `r"(?:\b\d{2,}[ \t]+(?:tests?|suites?|files?|passed)\b)|(?:\b(?:tests?|suites?|files?|passed)\b[ \t]*[:=]?[ \t]*\d{2,}\b)"`. It covers both shapes a test count is actually written in — digits-first (`689 tests`) and word-first (`Tests  84 passed`, the Vitest summary line) — while the gap between the count word and the number is a run of spaces/tabs with at most one `:` or `=`, and never the 19-character `. /... (CICD-01 / D-` run that separates `test` from `15` on this file's own `go test ./...` step name.

Why constrain the **gap** and not the digits: ci.yml line 80 is `      - name: go test ./... (CICD-01 / D-15)`. Its word `test` sits 19 characters before the digits `15`, inside any `[^\n]{0,40}?` window — so a rule written that way matches the file it is judging and reds the phase gate on the untouched tree, which falsifies every other plan's baseline assertion. Constraining the numeric side instead (`\d{3,}`) also clears that line, but drops the two-digit FE counts (`84`) this rule exists to catch. The gap is `[ \t]` rather than `\s` so it cannot span a newline (a `timeout-minutes: 45` line followed by a step named `tests` is then two characters away from a false match, not one).

(b) Word-boundary matches for `\b666\b` and `\b689\b` — the two Go-test totals the file must never pin.

The failure message must contain the word `count` and quote the matched text (e.g. `P6: ci.yml hard-codes a test-count phrase: %r`), because the mutation probe asserts on that word.

Confirm the baseline non-match once before writing the rule: compile the pattern and require **zero** matches against the current `.github/workflows/ci.yml`. A bare port such as `8084` and a year such as `1984` must not match either shape.
