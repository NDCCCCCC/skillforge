## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted PR code → runner | A fork PR's workflow-relevant content reaches the `ubuntu-latest` runner via `actions/checkout@v7` |
| `ci.yml` → branch protection contract | Job names `go` / `fe` / `docker` become required status checks; renaming them later breaks every open PR |
| Runner → lint scope decision | `only-new-issues` depends on a GitHub API call whose failure mode is a silent scope widening |
| `ci.yml` → repository secrets | Any `secrets.*` reference in the three new lines is a potential exfiltration path and an unavailability source |
