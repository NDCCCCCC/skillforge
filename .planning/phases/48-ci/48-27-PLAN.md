## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow YAML text with quoted scalars -> P1 trigger judge | A `#` inside a quoted scalar truncates the rest of the line for a non-quote-aware strip, so a real trigger key on the same physical line is invisible and the scan reports green |

| config-verify output -> P4 evidence line | A detector that appends its own bookkeeping into the log it then tests reports itself, not the tool, and its honest branch becomes unreachable |
