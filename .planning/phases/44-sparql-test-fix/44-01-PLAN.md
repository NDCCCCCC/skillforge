### Task 1: D-SPARQL-02 — Add dedup on nil-tier query path
- **File:** `internal/ontology/store/store.go:492-494`
- **Fix:** Replace the early-return with a dedup-aware walk when all of `subj,pred,obj` are empty:
  ```go
  // D-SPARQL-02: empty tiers = no filtering (admin baseline) + dedup.
  // Insert is no-dedup by design (audit-trail-preserving); dedup belongs at
  // the query layer so admin baseline doesn't return raw duplicates that the
  // tier path would have collapsed via the seen map (store.go:517).
  if len(allowedTiers) == 0 {
      if subj == "" && pred == "" && obj == "" {
          seen := map[string]bool{}
          out := make([]Triple, 0, len(s.all))
          for _, t := range s.all {
              key := t.S + "|" + t.P + "|" + t.O
              if seen[key] { continue }
              seen[key] = true
              out = append(out, t)
          }
          return out
      }
      return s.Query(subj, pred, obj)
  }
  ```
  Pattern-specific queries (one of `subj,pred,obj` non-empty) keep delegating to `Query` (which has index-driven narrow returns and rarely encounters raw duplicates in practice; if it does, callers can dedup at their own layer).
- **Regression:** `TestQueryScoped_NilTierDedupsDuplicates` in `internal/ontology/store/store_sparql_dedup_test.go` — insert duplicate `(s, p, o)` triple twice via `s.Insert(...)`, call `QueryScoped("", "", "", nil)`, assert `len(out) == 1`.   // OWL/RDFS ontology metadata predicates — always schema layer.

  // annotations subject to D-TIER-03 fail-closed semantics. Schema-subject

  if t.P == ns+"domain" || t.P == ns+"range" ||
      t.P == ns+"subClassOf" || t.P == ns+"subPropertyOf" {
