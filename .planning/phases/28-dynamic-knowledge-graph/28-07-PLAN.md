**Surface:** Graph API endpoints (GET /graph, /neighbors, /path); FE GraphCanvas with neighbor expansion.

### Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Client → BE (GET /neighbors) | chunk_id URL param crosses here; int64Parse validates |
| BE → ListMetadata | Metadata-only; no content exposed |
| Phase 27 → Phase 28 cache | Cross-phase hook; invalidation only |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-28-01 | Tampering | neighbors?chunk_id URL param | mitigate | parseLenientChunkID validates; non-numeric → 400 |
| T-28-02 | Denial of Service | BFS depth=max_hops explosion | mitigate | SKILLFORGE_GRAPH_NEIGHBOR_DEPTH_LIMIT=2 + SKILLFORGE_GRAPH_PATH_HOPS_LIMIT=4 hard caps; config enforced at handler entry |
| T-28-03 | Information Disclosure | citation_cooccur edge from audit VerdictJSON | mitigate | json.Unmarshal into typed struct; malformed frozen_args skipped with WARN; audit rows are already visible to operators |
| T-28-04 | Denial of Service | Jaccard pathological filename tokens | mitigate | Filename-only tokenization (not content); Jaccard threshold 0.3 prevents hairball; SKILLFORGE_GRAPH_MAX_EDGES=200 cap |
| T-28-05 | Spoofing | Citation co-occurrence fabricated by tampering audit table | accept | Audit rows are INSERT-only; tampering requires DB write access which implies already-broken trust boundary |
| T-28-06 | Repudiation | Graph cache serves stale edges after metadata update | mitigate | 5s TTL ensures max 5s staleness; edges are advisory (not trust boundary) |
| T-28-SC | Tampering | New npm package supply chain | mitigate | Phase 28 adds zero new npm packages; FE changes are existing package usage only |

### Section A: Graph API Verification (7 steps)

| Step | Action | Expected Result | Validation |
|------|--------|-----------------|------------|
| 1 | `curl -s http://localhost:8888/api/knowledge/graph \| jq '.tiers\|length'` | Returns N≥1 (one tier per active KB) | tiers count matches knowledge_bases.yaml entries |

| 3 | `curl -s "http://localhost:8888/api/knowledge/graph/neighbors?chunk_id=1&depth=1"` | Returns JSON with nodes + edges arrays | edges[].edge_type in {section_adjacent, version_chain, keyword_cooccur, citation_cooccur} |

## Knowledge Graph (Phase 28)

The knowledge graph (`GET /api/knowledge/graph`) reflects the registered knowledge bases and their document structure. Key capabilities:

- **N-dynamic nodes**: One node per active knowledge base (from KBRegistry), not a fixed 4-tier assumption
- **Deterministic relation edges**: Chunk relationships derived without LLM:
  - `section_adjacent`: consecutive chunk IDs within the same document

- **Neighbor API**: `GET /api/knowledge/graph/neighbors?chunk_id=X&depth=N` — explore relations
- **Path API**: `GET /api/knowledge/graph/path?from=X&to=Y&max_hops=N` — find relationships
- **Config-driven limits**: SKILLFORGE_GRAPH_MAX_NODES, MAX_EDGES, NEIGHBOR_DEPTH_LIMIT, PATH_HOPS_LIMIT
