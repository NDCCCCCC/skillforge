  <name>Task 1: Edge struct + constants + ComputeEdges skeleton</name>
  <files>internal/knowledge/graph_edges.go</files>
  <action>
Create internal/knowledge/graph_edges.go. Implement in this order:

1. Edge type and four constants (EdgeTypeSectionAdjacent, EdgeTypeVersionChain, EdgeTypeKeywordCooccur, EdgeTypeCitationCooccur). Weights are float64 in [0.0, 1.0].

2. EdgeGraph struct:
```go
type EdgeGraph struct {
    Edges []Edge
    // private adjacency list, built lazily on first Neighbors/Path call
    adj map[string][]Edge
}
```

3. ComputeEdges(metas []retriever.DocumentMeta) EdgeGraph — pure function, deterministic.

Inside ComputeEdges, derive edges in this order:
- **SectionAdjacent**: sort metas by (Tier, Source, ID); for each group of chunks with same (Tier, Source), emit Edge from chunk[i] to chunk[i+1] when IDs are consecutive (chunk[i].ID+1 == chunk[i+1].ID). Weight = 1.0.
- **VersionChain**: for each (Tier, Source) group, for each pair (a, b) where b.EffectiveFrom > a.EffectiveFrom AND a.EffectiveTo > 0 AND a.EffectiveTo <= b.EffectiveFrom, emit Edge a→b (a is superseded by b). Weight = 1.0.
- **KeywordCooccur**: tokenize each unique Source filename (strip extension, split on non-alphanumeric, lowercase, filter stop-words and tokens < 3 chars, sort); compute Jaccard(a, b) for every pair of chunks from different sources; emit Edge when Jaccard ≥ SKILLFORGE_GRAPH_JACCARD_THRESHOLD (default 0.3). Weight = Jaccard score. Use the stop-word map from research §2.
- **CitationCooccur**: scan audit rows via store.QueryAudit (filter Action matching "verdict"), parse VerdictJSON to extract cited chunk IDs, emit co-citation edges between all pairs of chunks in the same verdict. Weight = 1.0 / distinct_chunks_in_verdict. If store is nil or query fails, skip citation edges (degrade gracefully with log WARN — citation edges are optional enhancement per research §7 Risk R5).

Reuse int64ToChunkID from graph.go — copy the function body directly (do not import across packages for a 10-line helper). The cache key for memoization is the content-hash of sorted (Tier, Source, EffectiveFrom, EffectiveTo, ID) tuples.

For CitationCooccur: the verdict.Verdict struct has a Citations []Citation field. Parse the JSON with encoding/json. Skip malformed JSON with log WARN. A nil store.Skip — do not fail the whole edge computation.

DO NOT import any new Go packages. Pure stdlib: encoding/json, sort, strings, container/list for BFS (later plans), sync (TTL cache — later plan). Stop-word map is a package-level map[string]bool initialized inline.
