```go
// GraphCacheEntry holds the cached EdgeGraph and its expiry time.
type GraphCacheEntry struct {
    EdgeGraph *EdgeGraph
    ExpiresAt time.Time
    // Citation edges are cached separately with a longer TTL
    CitationEdgeGraph *EdgeGraph
    CitationExpiresAt time.Time
}

// cache is the sync.Map TTL cache. Key = "graph-v1" (single corpus).
var graphCache sync.Map

// graphCacheInvalidateHook is called by the Phase 27 upload handler after
// a successful upload. Bound at boot via SetGraphCacheInvalidateHook.
var graphCacheInvalidateHook func()

// SetGraphCacheInvalidateHook wires the cache invalidation seam.
func SetGraphCacheInvalidateHook(fn func()) { graphCacheInvalidateHook = fn }

// InvalidateCache clears both the main and citation sub-cache.
func InvalidateCache() {
    graphCache.Delete("graph-v1")
    graphCache.Delete("citation-v1")
    log.Printf("[WARN] knowledge: graph cache invalidated (upload/deactivate event)")
}
```

2. **GetOrCompute**: 
```go
func GetOrCompute(ctx context.Context, r retriever.Retriever) (*EdgeGraph, error) {
    if hook := graphCacheInvalidateHook; hook != nil {
        // Atomic read of function pointer (safe: assigned once at boot)
        _ = hook
    }
    // Check cache
    if entry, ok := graphCache.Load("graph-v1"); ok {
        ce := entry.(*GraphCacheEntry)
        if time.Now().Before(ce.ExpiresAt) {
            return ce.EdgeGraph, nil
        }
    }
    // Recompute
    metas, err := r.ListMetadata(ctx)
    if err != nil { return nil, err }
    eg := ComputeEdges(metas)
    eg.buildAdjacency()
    entry := &GraphCacheEntry{
        EdgeGraph: eg,
        ExpiresAt: time.Now().Add(TTL()),
    }
    graphCache.Store("graph-v1", entry)
    return eg, nil
}
```

3. **TTL()**: reads SKILLFORGE_GRAPH_CACHE_TTL_MS env var (int, default 5000ms), returns time.Duration.

4. **Citation sub-cache** (getCitationEdges): separate sync.Map key "citation-v1". On first call, scan audit via store.QueryAudit for verdict rows → derive citation co-occurrence edges → cache for 30s (SKILLFORGE_GRAPH_CITATION_CACHE_TTL_MS). If audit scan fails, log WARN and return empty EdgeGraph (do not fail the main cache). This sub-cache is invalidated independently when InvalidateCache is called.

5. **Auto-expiry goroutine** (optional, can be simple timer-per-entry or lazy eviction):
The simplest pattern: on every GetOrCompute call, check expiry and recompute if stale (lazy eviction). No background goroutine needed for v1.2. For the citation sub-cache, same lazy pattern.

The hook site: After SetDocUploadAuditHook is called in main.go (upload.go boot wiring at main.go:~770), ALSO call knowledge.SetGraphCacheInvalidateHook(func() { knowledge.InvalidateCache() }) — this is done in Plan 28-04 (main.go wiring). For Plan 28-03, just define the hook variable + setter + InvalidateCache function.

DO NOT import any new packages. stdlib only: sync, time, log, context.
