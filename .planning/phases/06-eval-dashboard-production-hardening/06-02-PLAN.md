<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/audit | untrusted query params cross into the backend; must not reach SQL unsanitized |
| client → /api/eval/reports/:ts | untrusted :ts path segment crosses into filesystem access; must be validated |
| admin token header → audit handler | bearer token must be compared in constant time; never logged |
| store layer → redaction projection | raw audit rows are privileged data; the projection enforces retention before leaving the backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-SQLI | Tampering | /api/audit query params | mitigate | Handler maps params to store.AuditFilter; store builds SQL with ? placeholders only. Existing T-3-SQLI regression (DROP TABLE survives) must stay green. |
| T-6-PATH | Tampering / Info disclosure | /api/eval/reports/:ts | mitigate | Strict regex `^[0-9T:-]+Z$` rejects `..`, `/`, `\`, and any non-timestamp path before `os.ReadFile`. Confined to eval/reports/. |
| T-6-IDOR | Info disclosure | /api/audit | mitigate | Binary admin split: no X-Admin-Token → retention-redacted rows only. Raw rows require SKILLFORGE_ADMIN_TOKEN env. v2 SCALE-* owns real RBAC. |
| T-6-TOKEN | Spoofing | X-Admin-Token check | mitigate | `crypto/subtle.ConstantTimeCompare`, NOT `==`. Token value never logged. |
| T-3-AUDIT | Tampering / Repudiation | audit row retention | mitigate | Redaction is READ-TIME ONLY in internal/server/audit.go. internal/store/sqlite/audit.go gains NO UPDATE or DELETE path. The meta-record (ts/session/skill/refusal/metrics) survives. |
| T-3-ISO | Info disclosure | session memory | mitigate | TestSessionIsolation50x5 exercises the existing `WHERE session_id=?` partition under -race. No new enforcement code is needed. |
| T-6-SC | Tampering | Go module installs | mitigate | No new Go dependencies in this plan. |
</threat_model>
