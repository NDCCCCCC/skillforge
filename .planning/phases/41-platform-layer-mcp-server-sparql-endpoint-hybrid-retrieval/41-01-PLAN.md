```go
// Triple is one RDF triple in JSON-serializable form.
type Triple struct {
    S          string       `json:"s"`
    P          string       `json:"p"`
    O          string       `json:"o"`
    Provenance *Provenance `json:"provenance,omitempty"`
}

// Provenance records the origin of one ABox triple.
type Provenance struct {
    SourceKind  string `json:"source_kind"`  // "file"|"emitter"|"induction"
    SourcePath  string `json:"source_path"`
    LineStart   int    `json:"line_start,omitempty"`  // 1-based, 0=N/A
    LineEnd     int    `json:"line_end,omitempty"`
    ExtractedAt string `json:"extracted_at"`  // RFC3339 UTC
}

// Query returns triples matching the (s, p, o) pattern; empty string is a wildcard.
func (s *Store) Query(subj, pred, obj string) []Triple

// QueryScoped returns triples filtered by tier. Schema-layer is never filtered.
// allowedTiers is the list of tier names (e.g. ["sql-guides", "权威"]).
func (s *Store) QueryScoped(subj, pred, obj string, allowedTiers []string) []Triple

// Adjacent1 returns deduplicated, sorted objects reachable from subj via pred (1-hop forward).
func (s *Store) Adjacent1(subj, pred string) []string

// Adjacent2 returns deduplicated, sorted objects reachable from subj via pred1 then pred2 (2-hop).
func (s *Store) Adjacent2(subj, pred1, pred2 string) []string
```

    Create `internal/server/platform/mcp/server.go` implementing the MCP server.

    Package: `internal/server/platform/mcp`
    Imports: `github.com/mark3labs/mcp-go/mcp"`, `internal/ontology/store`, `internal/knowledge/ecl`

    **NewMCPServer(kg *store.Store, serviceSkill string)** — constructor receiving the KG store reference and service_skill name.

    **Exported tools (per D-MCP-03/D-MCP-04/D-MCP-05/D-MCP-06):**

    1. `skf_query` — input: `{s?:string, p?:string, o?:string, limit?:int, offset?:int}` — calls `kg.Query(s, p, o)` then slices by offset/limit. Returns `{results:[{s,p,o,provenance?}], count, truncated}`. Uses `QueryScoped` internally with the tool's skill parameter (D-TRUST-01).

    2. `skf_skills` — input: none — queries KG for all `rdf:type skf:Skill` individuals. Returns `[{name, description, reads_tiers}]` where description comes from `skf:description` triple and reads_tiers from `skf:hasReadAccess` triples projected via Adjacent1.

    3. `skf_chunk_for(entity_iri string, max_hops int=1)` — input: entity IRI — calls KG `Adjacent1(entity, "skf:referencesTable")` to find related table IRIs, then reads ECL note metadata (section info from the note's source_path and line range). Returns `[{source_path, line_start, line_end, text_snippet}]`. Uses `QueryScoped` with the tool's skill (D-TRUST-01).

    4. `skf_schema` — input: none — returns TBox class hierarchy overview. Queries for all `rdf:type owl:Class` and `rdf:type owl:ObjectProperty` triples. Returns `{classes:[{iri, label}], properties:[{iri, domain, range}]}`.

    5. `skf_neighbors(uri string, hops int=1)` — input: entity URI + hops (1|2) — calls KG Adjacent1/Adjacent2 to find N-hop neighbors + edges. Returns `{nodes:[{id,label,kind}], edges:[{source,target,predicate}]}`.

    **Skill filtering (D-MCP-04):** Each tool accepts an optional `skill` string parameter. If absent, uses the server's `serviceSkill` configured at startup (from `SKILLFORGE_MCP_SERVICE_SKILL` env). The skill name is resolved to tier names via `resolveSkillTiers(skillName)` — reads `skf:hasReadAccess` triples for that Skill individual from the KG. Passes the resulting tier list to `QueryScoped`.

    **Error handling:** Return MCP error responses for invalid input. Never panic. Handler functions return structured error maps.

    **Transport:** stdio only (D-MCP-01). The server implements the MCP handler protocol via mark3labs/mcp-go's server framework. stdio transport is provided by the framework.
