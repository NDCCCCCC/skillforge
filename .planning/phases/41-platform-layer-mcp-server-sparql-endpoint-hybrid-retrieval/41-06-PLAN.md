    **Environment setup (must be at top):**
    ```bash
    #!/bin/bash
    set -e
    MSYS_NO_PATHCONV=1
    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    cd "$SCRIPT_DIR"
    ```

    **6 sections (a-f):**

    **a) Build** — `go build ./cmd/server/...` and `go build ./internal/server/...`. Must succeed.

    **b) Vet** — `go vet ./internal/server/...` and `go vet ./internal/server/platform/...`. Zero warnings.

    **c) Unit tests** — `go test ./internal/server/platform/... -count=1` (tests for SparqlQueryScoped, HybridSearchScoped, MCP tools). Also `go test ./internal/ontology/store/... -count=1 -run TestQueryScoped` (tier filtering regression).

    **d) MCP stdio test** — Test the MCP server tools via the mark3labs/mcp-go stdio interface. The test:
    1. Start the server with `SKILLFORGE_MCP_SERVICE_SKILL=compliance` env var.
    2. Send a JSON-RPC tool call for `skf_skills` via stdin.
    3. Assert the response contains tool names.
    4. Send `skf_query` with a known pattern and assert results are returned.

    Use the MCP protocol directly (not HTTP). The MCP server reads from stdin and writes to stdout.

    **e) SPARQL endpoint test** — `curl` against the running server:
    1. Start the server in background (or use `go test` with a test server).
    2. `curl -X POST http://localhost:8888/api/sparql -H "Content-Type: application/json" -d '{"s":"","p":"rdf:type","o":"skf:Skill","limit":10}' -H "X-Skill-Name: compliance"` → 200 with JSON.
    3. Without X-Skill-Name → 401.
    4. With invalid skill → 401.

    Use the same test server pattern as verify-phase-40.sh.

    **f) Hybrid recall test** — Run the hybrid retrieval pipeline on the Q1/Q4 subset of `eval/calibration.json`. Assert recall >= 0.85.

    Compute recall = (number of relevant docs retrieved in top-5) / (total relevant docs). Use the existing golden set labels.

    The hybrid pipeline should be testable without live Milvus — use a mock Milvus or test with the existing seeded data.

    **Section structure:**
    ```bash
    section() {
      local name="$1"; shift
      echo "[$name] $@"
      local start=$(date +%s)
      "$@" || { echo "FAIL: $name"; exit 1; }
      local elapsed=$(($(date +%s) - start))
      echo "PASS: $name (${elapsed}s)"
    }

    section "a: build" go build ./cmd/server/...
    section "b: vet" go vet ./internal/server/...
    section "c: unit tests" go test ./internal/server/platform/... -count=1
    section "d: MCP stdio" bash "$SCRIPT_DIR/verify_mcp_stdio.sh"
    section "e: SPARQL endpoint" bash "$SCRIPT_DIR/verify_sparql.sh"
    section "f: hybrid recall" bash "$SCRIPT_DIR/verify_hybrid_recall.sh"
    echo "ALL PASSED"
    ```

    **Exit code:** 0 on all pass, non-zero on first failure.
