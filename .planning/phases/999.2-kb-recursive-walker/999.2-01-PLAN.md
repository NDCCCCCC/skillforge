<action>
修改 `internal/knowledge/indexer.go` line 154-160 的 `Glob` 调用为 `WalkDir`：

1. 替换：
```go
pattern := filepath.Join(tierAbs, "*.md")
matches, err := filepath.Glob(pattern)
if err != nil {
    return fmt.Errorf("knowledge.Index: glob %s: %w", pattern, err)
}
sort.Strings(matches)
```

为：
```go
var matches []string
walkErr := filepath.WalkDir(tierAbs, func(path string, d fs.DirEntry, err error) error {
    if err != nil } return err }
    if d.IsDir() {
        // 跳过隐藏目录（如 .git），但保留根目录 tierAbs
        if path != tierAbs && strings.HasPrefix(d.Name(), ".") {
            return filepath.SkipDir
        }
        return nil
    }
    if !strings.HasSuffix(d.Name(), ".md") {
        return nil
    }
    matches = append(matches, path)
    return nil
})
if walkErr != nil {
    return fmt.Errorf("knowledge.Index: walk %s: %w", tierAbs, walkErr)
}
sort.Strings(matches)
```

2. 文件顶部加 `import "io/fs"` 和 `import "strings"`（如果还没有）。
3. **不要**删除现有 `maxDocBytes` 检查（line 175 区域）——那是 body size 校验，与目录递归无关。
4. **不要**改 `rel := filepath.Rel(knowledgeDir, path)` 逻辑——它已经自动保留子目录。
</action>
