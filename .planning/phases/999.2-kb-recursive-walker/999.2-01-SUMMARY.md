1. **`internal/knowledge/indexer.go`** — Extracted the recursive-walk logic from `Index()` into a new package-private helper `walkTier(absDir string) ([]string, error)`. 3. **`internal/knowledge/walk_test.go`** (new) — 5 regression tests for `walkTier`:

   - `TestWalk_DeterministicAcrossCalls` — call-twice consistency
   - `TestWalk_EmptyDirReturnsEmpty` — empty dir returns empty slice, no error

4. **`internal/knowledge/graph_filename_test.go`** (new) — `TestFilenameOf_PreservesSubdirectory` with 8 subcases pinning the `strings.Cut` direction (before vs after separator) so the bug encountered mid-execution cannot regress.

## Issues Encountered & Resolutions

1. **Forgot to rebuild `cmd/server` binary before first restart.** Ran `go build ./internal/knowledge/` thinking that would refresh the server binary. The binary still had the old code; graph showed wrong filenames; I thought the fix didn't work. ~10 minutes lost. **Lesson saved to memory**: `fix-build-cmd-server-before-restart`.

2. **`strings.Cut` direction bug.** Wrote `rest, _, ok := strings.Cut(source, "/")` thinking `rest` was the AFTER portion. Actually `strings.Cut` returns `(before, after, found)`, so `rest` was `before` (the tier slug). Symptom: `filenameOf("sql-guides/汽车险/037_xxx.md")` returned `"sql-guides"`. **Lesson saved to memory**: `fix-strings-cut-direction`.

## Lessons for Future Phases

1. **Always run `go build -o skillforge-server-dev-new ./cmd/server` before restart.** Package builds (`go build ./internal/X/`) don't refresh the server binary.
2. **`strings.Cut` returns (before, after, found).** Don't name the first variable `rest` — it confuses future readers.
3. **Filename display matters.** A code change that's "correct" but invisible to operators (subdir hidden in basename) doesn't deliver value. The graph.go filenameOf fix was as important as the walker change.
4. **Phase 999.x backlog convention works.** Using `999.2-kb-recursive-walker` (following `999.1-hierarchical-markdown-splitter-decision`) keeps KB markdown concerns grouped without disrupting milestone phase numbering.
