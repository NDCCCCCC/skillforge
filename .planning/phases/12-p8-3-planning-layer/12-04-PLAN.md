## Design Rationale

**Why GET /api/run/:id/plan (vs /api/session/:id/plan)?** PLAN-05 replay is keyed by run_id (one DeepAgent run = one plan), not session_id (one user session can have many runs). The path distinguishes plan replay from session history (which is keyed by session_id). Mirrors Phase 11 approval routes which are keyed by session_id.

**Why planApproveHandler mirrors approvalPostHandler verbatim?** D11-CONTEXT §Deferred Ideas explicitly designed Phase 12 plan approval to reuse the Phase 11 HITL infrastructure. P12-L7 zero-schema-divergence means the plan_approve Tool uses the same ApprovalDecision struct, audit_writer seam, dual-table snapshot — the HTTP endpoint is the same pattern with target="plan_approve". No new validation logic, no new auth, no new error handling. The only addition is the routing path /api/run/:id/plan/:approvalId/approve.

**Why ExtractVerdictJSONWithStructuredOutput vs. just calling ExtractJSON?** RF-5 LOW confidence: GLM-5.2 + DeepAgent may produce prose + tool calls, not strict JSON output. ExtractJSON (Phase 3 OOS-1 fix) handles JSON fences + trailing prose, but if the LLM literally produces no JSON in the final message, ExtractJSON returns empty. The structured-output final step calls the chatModel again with `response_format=json_object` + the Phase 2 systemPrompt verbatim — this is the canonical Ragas-style extraction (D6 reversed: Go-native evaluator still ports Ragas prompts verbatim). If structured output is supported (GLM-5.2 verified OpenAI-compatible), the second call produces parseable JSON; if not, ExtractJSON fallback handles the first-call's prose.

**Why spike-deep is operator-gated (not hermetic)?** Same pattern as Phase 9 spike-history (GEVL-08 hard gate) + Phase 11 spike-hitl. The 50-case measurement requires live GLM-5.2 + Milvus + BGE-M3 stack, which is operator environment dependent. Hermetic tests verify the spike infrastructure works (dry-run + schema validation + missing-env error path); live measurement is operator-actionable. Results reported in 12-08 acceptance gate.
