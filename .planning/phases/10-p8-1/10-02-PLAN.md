## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BE → LLM (rewriter) | `QueryRewriter.Rewrite` is a lightweight LLM call with `MaxTokens=80` + 2s timeout. Failure falls back to original query (no error, no block). The rewriter never sees raw chunk text — only sanitized history messages. |
| BE → LLM (classifier) | `RefusalClassifier.Classify` is the bottleneck. The input struct has no `History` field (D10-A1). The LLM call has `MaxTokens=60` + 3-retry loop + default-deny on parse failure. |
| BE → LLM (verdict) | The verdict LLM still sees the same 2-message shape (System + User) when history is empty. With history, the slice grows but the LAST user message (the evidence) is byte-identical. |
| BE → sqlite | `audit_meta` is INSERT-only (sibling table). T-3-AUDIT invariant preserved (no UPDATE/DELETE on audit OR audit_meta). |
