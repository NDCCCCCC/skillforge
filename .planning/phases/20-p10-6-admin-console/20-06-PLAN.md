### Task 2: admin_audit.go — admin audit sub-view endpoint

**Files:** `internal/server/admin_audit.go`

**Action:** Create `GET /api/admin/audit` handler:

1. Gate: `if !isAdminRequest(c) { 403 }`
2. Query audit rows filtered by `actor_type = 'admin'` — use `store.QueryAudit` with a new `ActorType` filter field, OR add `ActorType` to `AuditFilter`
3. Apply redaction via `redact()` function (Phase 6 reuse)
4. 200 with filtered audit rows

Response is the same shape as `GET /api/audit` but filtered to admin-only rows.

If `AuditFilter` does not have an `ActorType` field, add it to the filter struct in `store.go` and implement the SQL filter in `sqlite/audit.go`.

```go
// In store.go AuditFilter:
type AuditFilter struct {
    // ... existing fields
    ActorType string // "user" | "admin" | "" (empty = all)
}
```

```go
// In admin_audit.go:
func (s *Deps) adminAuditHandler(ctx context.Context, c *app.RequestContext) {
    if !isAdminRequest(c) {
        c.JSON(http.StatusForbidden, map[string]string{"error": "admin token required"})
        return
    }
    if s.Store == nil {
        c.JSON(http.StatusServiceUnavailable, graphResponseError{Error: "audit store not initialized"})
        return
    }

    filter := store.AuditFilter{ActorType: "admin"}
    rows, err := s.Store.QueryAudit(ctx, filter)
    if err != nil {
        c.JSON(http.StatusInternalServerError, graphResponseError{Error: "audit query failed"})
        return
    }

    redact(rows, auditRetention(), time.Now(), true) // isAdmin=true → admin sees raw rows
    c.JSON(http.StatusOK, rows)
}
```

**Verify:** `grep -cE "POST|PUT|DELETE|PATCH" internal/server/admin_audit.go` == 0
**Done:** admin_audit.go exists with actor_type filter and redaction applied
