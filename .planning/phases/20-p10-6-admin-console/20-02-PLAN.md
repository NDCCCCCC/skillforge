### Task 1: admin_batches.go handler

**Files:** `internal/server/admin_batches.go`

**Action:** Create `GET /api/admin/batches` handler mirroring `kpi_admin.go` structure:

1. Gate: `if !isAdminRequest(c) { 403 }`
2. Call `s.Store.ListImportBatches(ctx, "")` — empty string returns all datasets (new store method or reuse `ListImportBatches(dataset string)` by iterating known datasets)
3. If `s.Store == nil`: 503
4. 200 with JSON array of batch rows

The store's `ListImportBatches` takes a `dataset` filter. For the admin view showing all batches, either:
- Add a new `ListAllImportBatches(ctx)` method, OR
- Use an empty string `""` if the store already treats `""` as "all datasets"

**NOTE:** If `ListImportBatches` does NOT support empty-string for "all", add `ListImportBatchesAll(ctx context.Context) ([]store.ImportBatchRow, error)` to the store interface and implement it in sqlite package.

### Task 3: ImportBatchList component

**Files:** `web/src/components/admin/ImportBatchList.tsx`

**Action:** Create the ImportBatchList component:

1. `useEffect` fetching `GET /api/admin/batches` with `X-Admin-Token` header
2. Render a `<table>` with columns: Dataset | Status | Row Count | Raw Size | Discarded At
3. Status badge colors per UI-SPEC:
   - `completed`: green badge (status-compliant)
   - `pending`: amber badge (status-needs-info)
   - `running`: amber badge with subtle CSS pulse animation
   - `failed`: red badge (status-non-compliant)
4. Raw size formatted as human-readable (KB/MB)
5. Empty state: "暂无导入批次" heading + "数据导入后将显示在此处" body

```typescript
function ImportBatchList() {
  const [batches, setBatches] = useState<ImportBatchRow[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const token = /* read from env or store */;
    fetch('/api/admin/batches', {
      headers: { 'X-Admin-Token': token }
    })
      .then(r => r.json())
      .then(data => { setBatches(data.batches); setLoading(false); })
      .catch(() => setLoading(false));
  }, []);

  if (loading) return <LoadingSkeleton />;
  if (batches.length === 0) return <EmptyState />;

  return (
    <table>
      <thead>
        <tr>
          <th>Dataset</th>
          <th>Status</th>
          <th>Row Count</th>
          <th>Raw Size</th>
          <th>Discarded At</th>
        </tr>
      </thead>
      <tbody>
        {batches.map(batch => (
          <tr key={batch.batch_id}>
            <td>{batch.dataset}</td>
            <td><StatusBadge status={batch.status} /></td>
            <td>{batch.desensitized_row_count.toLocaleString()}</td>
            <td>{formatBytes(batch.raw_size_bytes)}</td>
            <td>{batch.discard_ts ? formatDate(batch.discard_ts) : '—'}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

Where `StatusBadge` renders:
- `completed` → `<span className="text-xs bg-green-500/20 text-green-400 px-2 py-0.5 rounded">completed</span>`
- `pending` → amber
- `running` → amber + `animate-pulse`
- `failed` → red

Per UI-SPEC: no action buttons, no edit icons. Read-only enforcement is structural.

**Verify:** File exists, renders table with status badges, empty state when API returns empty array
**Done:** ImportBatchList.tsx exists with correct table layout, status badges, and empty state
