## Tasks

### Task 1: KPIDefinitionList component

**Files:** `web/src/components/admin/KPIDefinitionList.tsx`

**Action:** Create the KPI definition list component:

1. `useEffect` fetching `GET /api/admin/kpis` with `X-Admin-Token` header
2. Render a `<table>` with columns: Function Name | Signature | Last Called | Call Count
3. `signature` field rendered in `font-mono` (monospace font) per UI-SPEC
4. `last_called` rendered as relative time (e.g., "2 hours ago") or formatted date
5. `call_count` derived from `latest_calls` — if a KPI name is in `latest_calls`, count is 1+; if absent, count is 0

```typescript
interface KPIRow {
  name: string;
  description: string;
  params_summary: string;
  dataset: string;
}

function KPIDefinitionList() {
  const [data, setData] = useState<{signature: string; kpis: KPIRow[]; latest_calls: Record<string, string>} | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const token = /* read from env or store */;
    fetch('/api/admin/kpis', {
      headers: { 'X-Admin-Token': token }
    })
      .then(r => r.json())
      .then(d => { setData(d); setLoading(false); })
      .catch(() => setLoading(false));
  }, []);

  if (loading) return <LoadingSkeleton />;
  if (!data || data.kpis.length === 0) {
    return (
      <div className="text-center py-12">
        <h3 className="text-lg font-semibold">暂无 KPI 定义</h3>
        <p className="text-sm text-text-muted mt-1">在 kpis/ 目录添加 YAML 文件注册新 KPI</p>
      </div>
    );
  }

  return (
    <table>
      <thead>
        <tr>
          <th>Function Name</th>
          <th>Signature</th>
          <th>Last Called</th>
          <th>Call Count</th>
        </tr>
      </thead>
      <tbody>
        {data.kpis.map(kpi => {
          const lastCalled = data.latest_calls[kpi.name];
          return (
            <tr key={kpi.name}>
              <td className="font-medium">{kpi.name}</td>
              <td>
                <code className="font-mono text-xs text-text-muted">{kpi.params_summary}</code>
              </td>
              <td className="text-sm text-text-muted">
                {lastCalled ? formatRelativeTime(lastCalled) : <span className="text-text-muted">Never</span>}
              </td>
              <td className="text-sm">
                {lastCalled ? `1+` : <span className="text-text-muted">0</span>}
              </td>
            </tr>
          );
        })}
      </tbody>
    </table>
  );
}
```

Per UI-SPEC: **NO edit button, NO kebab menu, NO action column.** Files are the sole source of truth. This is read-only by construction.
