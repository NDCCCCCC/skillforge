### Task 3: ScheduledTaskList component

**Files:** `web/src/components/admin/ScheduledTaskList.tsx`

**Action:** Create the scheduled task list component:

1. `useEffect` fetching `GET /api/admin/schedules` with `X-Admin-Token` header
2. Render a `<table>` with columns: Skill | Cron | 上次运行 | 状态 | Drift | 下次执行
3. Cron expressions rendered in `font-mono` per UI-SPEC
4. Status badge: completed (green), running (amber), failed (red), idle (gray)
5. Drift badge: only shown when `drift_status === 'drifted'` — amber badge
6. Next fire time formatted as absolute datetime

```typescript
function ScheduledTaskList() {
  const [schedules, setSchedules] = useState<ScheduleRow[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const token = /* read from env or store */;
    fetch('/api/admin/schedules', {
      headers: { 'X-Admin-Token': token }
    })
      .then(r => r.json())
      .then(d => { setSchedules(d.schedules); setLoading(false); })
      .catch(() => setLoading(false));
  }, []);

  if (loading) return <LoadingSkeleton />;
  if (schedules.length === 0) {
    return (
      <div className="text-center py-12">
        <h3 className="text-lg font-semibold">暂无定时任务</h3>
        <p className="text-sm text-text-muted mt-1">在 Skill 的 report_schedule 字段配置调度</p>
      </div>
    );
  }

  return (
    <table>
      <thead>
        <tr>
          <th>Skill</th>
          <th>Cron 表达式</th>
          <th>上次运行</th>
          <th>状态</th>
          <th>Drift</th>
          <th>下次执行</th>
        </tr>
      </thead>
      <tbody>
        {schedules.map(schedule => (
          <tr key={schedule.run_id}>
            <td className="font-medium">{schedule.skill_id}</td>
            <td>
              <code className="font-mono text-xs text-text-muted">{schedule.cron_expr}</code>
            </td>
            <td className="text-sm text-text-muted">
              {schedule.last_fired_at ? formatDate(schedule.last_fired_at) : '—'}
            </td>
            <td><StatusBadge status={schedule.status} /></td>
            <td>
              {schedule.drift_status === 'drifted' && (
                <span className="text-xs bg-amber-500/20 text-amber-400 px-2 py-0.5 rounded">drift</span>
              )}
            </td>
            <td className="text-sm text-text-muted">
              {schedule.next_fire_at ? formatDate(schedule.next_fire_at) : '—'}
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

Per UI-SPEC: **NO edit/create/delete buttons.** Read-only enforcement is structural.

**Verify:** No action buttons in table; cron_expr rendered in `font-mono`
