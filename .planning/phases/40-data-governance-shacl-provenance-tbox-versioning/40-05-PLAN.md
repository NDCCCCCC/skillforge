Implement `RollbackTBox(targetVersion int, reason string) (int, int, error)` in induction.go:

**Signature**:
```go
// RollbackTBox reverts to a previous TBox version.
// Returns (new_version, post_rollback_violation_count, error).
// Writes v{N+1} = copy of target version TTL, updates pointer,
// rebuilds KG from new TTL, and triggers SHACL revalidation (D-PROV-09).
func (m *Manager) RollbackTBox(targetVersion int, reason string) (int, int, error)
```

**Algorithm** (per D-LOG-03 + D-PROV-09):
1. Read the target version TTL file: `skillforge_tbox.v{targetVersion}.ttl`
2. Read current version: `m.readVersion()` → current
3. Compute next = current + 1
4. Write `skillforge_tbox.v{next}.ttl` = copy of target version TTL
5. Update pointer `skillforge_tbox.ttl` to new content
6. Update `tbox_version.txt` to next
7. Clear KG store: iterate all subjects via Query("", "", "") and call DeleteSubject for each
8. Reload KG from new TTL via `kg.LoadFromTurtle(newTTLContent)`
9. Trigger snapshot write: `kg.WriteSnapshot()` → snapshot path
10. Append changelog entry: `who = "system:rollback"`, `what.removed = []string{all IRIs from the rolled-back version}`, `what.added = []string{}`, `why = fmt.Sprintf("rollback to v%d: %s", targetVersion, reason)`
11. Return (next, violation_count, nil) — violation_count comes from calling SHACL validate (the validate.go from plan 40-01)

**Changelog what.removed derivation**:
- Parse the target TTL and extract all declared IRIs (classes, properties)
- Or simpler: report the version numbers, not IRI lists (D-LOG-02 says IRI lists but the IRI extraction from TTL adds complexity)
- Per D-LOG-02: `what` = {added: [], removed: [IRIs dropped from previous version]}
- For rollback, the removed set = all IRIs that were in versions > targetVersion but are now gone

**KG clear + reload**:
```go
// Clear all triples
for _, t := range m.kg.Query("", "", "") {
    m.kg.DeleteSubject(t.S)  // DeleteSubject removes all triples with this subject

newTTL, err := os.ReadFile(filepath.Join(m.dataDir, fmt.Sprintf("skillforge_tbox.v%d.ttl", targetVersion)))

    return 0, 0, fmt.Errorf("read target TTL v%d: %w", targetVersion, err)
}
if _, err := m.kg.LoadFromTurtle(string(newTTL)); err != nil {
    return 0, 0, fmt.Errorf("load new TTL into KG: %w", err)
}
```

```go
func (s *Deps) adminOntologyRollbackHandler(ctx context.Context, c *app.RequestContext) {
    dep, ok := s.requireOntology(c)
    if !ok { return }

    var req rollbackRequest
    if err := c.BindAndValidate(&req); err != nil {
        c.JSON(http.StatusBadRequest, graphResponseError{Error: "invalid body: " + err.Error()})
        return
    }
    if req.TargetVersion <= 0 {
        c.JSON(http.StatusBadRequest, graphResponseError{Error: "target_version must be positive"})
        return
    }

    newVersion, newViolations, err := dep.Induction.RollbackTBox(req.TargetVersion, req.Reason)
    if err != nil {
        if errors.Is(err, os.ErrNotExist) || strings.Contains(err.Error(), "no such file") {
            c.JSON(http.StatusNotFound, graphResponseError{Error: "version not found"})
            return
        }
        c.JSON(http.StatusInternalServerError, graphResponseError{Error: "rollback: " + err.Error()})
        return
    }
    c.JSON(http.StatusOK, rollbackResponse{Version: newVersion, NewViolations: newViolations})
}
```

```go
func (m *Manager) ListChangelog() ([]ChangelogEntry, error) {
    path := filepath.Join(m.dataDir, "tbox_changelog.jsonl")
    data, err := os.ReadFile(path)
    if err != nil {
        if os.IsNotExist(err) {
            return []ChangelogEntry{}, nil
        }
        return nil, err
    }
    var entries []ChangelogEntry
    for _, line := range strings.Split(strings.TrimSpace(string(data)), "\n") {
        if line == "" { continue }
        var e ChangelogEntry
        if err := json.Unmarshal([]byte(line), &e); err != nil {
            continue  // skip malformed lines
        }
        entries = append(entries, e)
    }
    // Newest first
    sort.Slice(entries, func(i, j int) bool { return entries[i].Version > entries[j].Version })
    return entries, nil
}
```
