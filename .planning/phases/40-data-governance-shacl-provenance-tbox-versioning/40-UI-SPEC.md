# Phase 40 — UI Design Contract

> Visual and interaction contract for Phase 40 `/admin/governance` — SHACL 校验报告（绿/黄/红）+ Provenance 溯源图谱（Cytoscape.js）+ TBox 版本演进 timeline（rollback）。This continues the v1.4 **consistency-locking** regime: the existing admin console design language is LOCKED; this phase extends it with one new tab (the 10th) plus two surgical modifications (KGQueryPanel tier selector + KGTriple provenance column). Every token, class idiom, and pattern below is inherited from the implemented console (`web/src/components/admin/`) and the approved 39-UI-SPEC — not redesigned. Generated by gsd-ui-researcher.

**Dependency change (exactly one, sanctioned by 40-CONTEXT):** `cytoscape` (plain npm package, `^3.x` — planner pins the exact latest stable) for the provenance graph (SC-6 点名). Integration rules:

- **No React wrapper library** (`react-cytoscape*` family is unmaintained) — mount via a container `ref` + `useEffect`, destroy on unmount (`cy.destroy()`).
- No cytoscape layout/layout plugin extensions (no dagre/cose-bilkent) — use the built-in `'breadthfirst'` layout (§Component 5).
- Graph styling reads CSS variables at mount via `getComputedStyle(document.documentElement).getPropertyValue('--color-…')` — never hardcoded hex. A `MutationObserver` on `documentElement` for `data-theme` changes re-creates the graph so the light-theme mirror applies (ThemeToggle compatibility).
- Vitest: jsdom has no canvas — the graph component's tests `vi.mock('cytoscape')` and assert on container/fallback/panel markup, not canvas output.

Everything else: **zero new tokens, zero new CSS files, no shadcn CLI components.** New files follow the Phase 38/39 folder pattern: `web/src/components/admin/governance/{GovernanceTab.tsx, ShaclReportView.tsx, ProvenanceGraphView.tsx, TimelineView.tsx, governanceApi.ts, types.ts}` plus wiring in `AdminDashboard.tsx` + `app-store.ts`; modifications to `ontology/{KGQueryPanel.tsx, types.ts, ontologyApi.ts}`.

## Typography

Inherited from theme.css `--text-*` tokens. 4 sizes × 2 weights, no additions.

| Role | Size | Weight | Line Height |

### 2. Types + API (new: `web/src/components/admin/governance/types.ts`, `governanceApi.ts`)

`governanceApi.ts` mirrors `pipelineApi.ts`: `GovernanceApiError extends Error` carrying `{status, message}` (server RAW error envelope unwrapped verbatim; network → `{status: 0, '网络错误'}`); `X-Admin-Token` from `localStorage sf_admin_token`. FE contract shapes (snake_case JSON, console convention; planner aligns BE DTO names):

```typescript
export type ShaclHealth = 'ok' | 'warn' | 'error';
export type ViolationSeverity = 'error' | 'warning';
export interface ShaclViolation {
  severity: ViolationSeverity;
  entity: string;            // entity URI; '(global)' for shape-level
  constraint: string;        // sh:minCount | sh:class | provenance-missing | …
  detail: string;            // engine message, rendered verbatim
  source_path?: string;      // SC-1: source file
  line_start?: number;       // D-PROV-05: 1-based
  line_end?: number;
}
export interface QuarantinedEntity {
  entity: string;
  triple_count: number;
  violations: ShaclViolation[];
}
export interface ShaclReport {
  health: ShaclHealth;
  error_count: number;
  warning_count: number;
  warnings: ShaclViolation[];
  quarantined: QuarantinedEntity[];
  triple_count: number;
  shapes_path: string;       // 零硬编码: surface the configured path
  validated_at: string;      // RFC3339
  trigger: 'boot' | 'rollback';
}
export type ProvenanceKind = 'file' | 'emitter' | 'induction';
export interface ProvenanceInfo {
  source_kind: ProvenanceKind;
  source_path: string;       // file path | emitter:v{N} | proposal id (D-PROV-02)
  line_start?: number;
  line_end?: number;
  extracted_at: string;      // RFC3339 UTC (D-PROV-11)
}
export interface GraphNode {
  id: string;                // entity URI or file path
  kind: 'file' | 'note' | 'table' | 'skill' | 'skillmd' | 'quarantined';
  label: string;
  provenance?: ProvenanceInfo; // absent on file/skillmd nodes (they ARE the source)
  tier?: string;             // belongsToTier projection, when present
}
export interface GraphEdge { source: string; target: string; }
export interface ProvenanceGraph { nodes: GraphNode[]; edges: GraphEdge[]; }
export type ChangelogWho = 'admin' | 'induction:llm' | 'system:rollback';
export interface ChangelogEntry {
  version: number;           // resulting version v{N}
  who: ChangelogWho;         // D-LOG-02 enum
  when: string;              // RFC3339
  what: { added: string[]; removed: string[] };  // IRI lists (D-LOG-02)
  why: string;               // LLM reasoning | admin note | rollback target+reason
}
```

API calls (route names in **bold** are pinned; others planner-final, FE centralizes them in governanceApi.ts so renaming is one-file):

- `fetchShaclReport()` → `GET /api/admin/governance/shacl`
- `fetchProvenanceGraph()` → `GET /api/admin/governance/provenance`
- `fetchChangelog()` → `GET /api/admin/ontology/changelog` → `{ current_version: number, entries: ChangelogEntry[] }`
- `rollbackTBox(targetVersion: number, reason?: string)` → **`POST /api/admin/ontology/rollback`** (name PINNED in 40-CONTEXT code_context, D-TBox-03) — body `{ target_version, reason }`; response must carry the resulting version + post-rollback SHACL delta (D-PROV-09: 成功提示带本次新增 violation 数) — planner DTO, minimum `{ version, new_violations }`.
- `runPipeline()` → **`POST /api/admin/pipeline/run`** (existing Phase 39 route — the backfill CTA reuses it; no new endpoint).
- KG query extension: existing `fetchKGQuery(s, p, o)` gains optional `skill` param (`&skill={name}`).

All GETs fire on view mount (per-view lazy fetch, switch back uses cached result + manual re-mount refetch is acceptable). **No polling interval** — see §Interaction Behaviors.

Search matches on node `id` and `label`, case-insensitive substring; no match → inline muted line 「未找到实体 {q}」 (never a toast).
- Node click → detail panel (§ layout): rows IRI / 来源 badge / 路径 (mono, break-all) / 行号 `L{start}–L{end}` / 时间 `extracted_at` / tier. `file`/`skillmd` nodes show 「源文件」 in the 来源 row and omit 时间/行号. Quarantined nodes additionally show a non-compliant line 「已隔离：{first constraint}」.
- Empty state (graph with 0 nodes): container replaced by empty hero 「暂无溯源数据 — 运行 ECL 后生成溯源链」 (`py-12`, ImportBatchList idiom). Load error: inline danger line 「溯源图谱加载失败（点击重试）」.
- Accessibility: canvas carries `role="img"` + `aria-label="溯源图谱：{nodes.length} 个实体、{edges.length} 条关系"`; the search input is the keyboard path to any entity (canvas itself is pointer-only — accepted for this internal admin surface, consistent with the console's existing meter/tooltip tolerance).

## Interaction Behaviors

### Rollback lifecycle (the phase's one consequential action)

1. Click 「回滚到此版本」 on a historical entry → `window.confirm('回滚到 v{M}？将写入新版本 v{N+1}、重建 KG 并自动重跑 SHACL 校验；失效引用实体将进入隔离区。')` (D-LOG-03 single-mechanism semantics + D-PROV-09 auto-revalidation, stated before commit). Cancel = no-op.
2. Confirmed → POST `/api/admin/ontology/rollback` with `{ target_version: M }`. Button shows disabled during flight; **no optimistic success**.
3. Success → success toast 「已回滚至 v{M}（当前 v{N+1}）· 新增 {k} 条 violation」 (D-PROV-09: the count is mandatory — if the server omits it, render 「已回滚至 v{M}（当前 v{N+1}）」 and log; never fabricate a count). Then: refetch changelog + SHACL report + provenance graph (all three surfaces are affected by the KG rebuild) and switch the active view to `shacl` so the post-rollback validation result is immediately visible.
4. Failure (409 / 404 / 500 / network) → error toast 「回滚失败：{真实原因}」; state unchanged. No auto-retry.

### Run ECL 回填 lifecycle (yellow-zone backfill)

1. Click 「Run ECL 回填」 → `window.confirm('运行 ECL 管线？将重建 sql-guides 的切块、实体抽取与索引（幂等操作，可重复执行），并同时回填 provenance 与 belongsToTier。')` — the 39-UI-SPEC Run copy extended with the backfill clause (same endpoint, same semantics, so the confirm must carry both facts).
2. Confirmed → POST `/api/admin/pipeline/run` (existing 39 route). Success → info toast 「ECL 管线已启动 — 前往 ECL 管线 页查看进度」; 409 → 「管线正在运行中，请等待完成」; 403/503/network → error toast with real reason.
3. **The governance report does NOT live-refresh afterwards** — SHACL runs at boot and after rollback only (runtime re-validation API explicitly deferred in 40-CONTEXT). The banner meta line 「报告反映最近一次校验」 + validated_at is the honesty mechanism. Rendering a 「重新校验」 button is FORBIDDEN (fake capability — no endpoint exists).

### Data fetching

- Per-view fetch on mount; no polling anywhere in this tab (nothing server-side changes without an admin action or a reboot — polling would be motion without information, and the ECL pipeline already owns run-progress polling in its own tab).
- Fetch errors never blank the view: skeleton → error-line-with-retry trio per view; the health banner renders its own muted error line 「治理状态加载失败（点击重试）」 when the SHACL fetch fails, and the views below still function.

## Honesty & Trust-Semantics Rules (console red lines)

1. **No fake re-validation.** SHACL runs at boot and after rollback only; no 「重新校验」 button (runtime re-validation API deferred per 40-CONTEXT). The banner's 校验时点 + trigger + 「报告反映最近一次校验」 line is the required staleness disclosure.
2. **No fake recovery.** The only backfill control reuses the real `POST /api/admin/pipeline/run`; progress lives in the ECL 管线 tab (the toast says so). No 「一键修复」「自动修复隔离」 controls (auto-fix deferred).
3. **Rollback never destroys.** Copy frames rollback as 写入新版本 v{N+1} (forward-only log per D-LOG-03); forbidden strings: 「删除版本」「覆盖历史」「清空」.
4. **No fabricated counts.** Violation counts, quarantine counts, and the rollback new-violation count come from server responses only; omit rather than invent.
5. **Fail-closed shown, not softened.** The tier demo never displays a 「隐藏 N 条」 figure for filtered-out entities; filtered results simply exclude them, and the summary line shows only the visible count.
6. **Errors verbatim.** Server `error` bodies render as-is after the zh-CN prefix (回滚失败：/ 启动失败：); network failures render 网络错误, never a fabricated status.
7. **Report is read-only.** No shape editing, no quarantine-unlock button, no shapes hot-reload control — all three are deferred or nonexistent surfaces.
