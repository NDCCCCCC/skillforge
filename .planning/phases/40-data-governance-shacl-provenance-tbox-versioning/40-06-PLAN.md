```go
// adminGovernanceShaclHandler implements GET /api/admin/governance/shacl.
// Returns the cached SHACL report from boot (shacl.Report shape).
// No live re-validation — report is from boot or post-rollback.
func (s *Deps) adminGovernanceShaclHandler(ctx context.Context, c *app.RequestContext) {
    dep, ok := s.requireOntology(c)
    if !ok { return }

    // Report is cached on the store (set by boot validation or rollback)
    report := dep.KG.GetShaclReport()  // returns shacl.Report or nil
    if report == nil {
        c.JSON(http.StatusServiceUnavailable, graphResponseError{Error: "report not available"})
        return
    }
    c.JSON(http.StatusOK, report)
}
```

**GET /api/admin/governance/provenance handler**:
Builds the graph data from KG + quarantine:

```go
// ProvenanceGraph DTO
type ProvenanceGraph struct {
    Nodes []GraphNode
    Edges []GraphEdge
}
type GraphNode struct {
    ID           string   `json:"id"`
    Kind         string   `json:"kind"`  // "file"|"note"|"table"|"skill"|"skillmd"|"quarantined"
    Label        string   `json:"label"`
    Provenance   *store.Provenance `json:"provenance,omitempty"`
    Tier         string   `json:"tier,omitempty"`
}
type GraphEdge struct {
    Source string `json:"source"`
    Target string `json:"target"`
}
```

Graph construction algorithm:
1. Walk all triples in KG
2. For each triple with provenance (non-nil Provenance):
   - If O looks like a file path (contains `/` or `.md`) → emit `file` node
   - If S is a note URI (note_N) → emit `note` node
   - If S is a table URI (tbl_X) → emit `table` node
   - Edges: source_path → note → table
3. Also emit nodes for quarantined entities (kind = "quarantined")
4. Skill/SKILL.md nodes: from KG triples where O = skf:Skill or S = skill_N

```go
func (s *Deps) adminGovernanceProvenanceHandler(...) {
    dep, ok := s.requireOntology(c)
    if !ok { return }

    nodes, edges := buildProvenanceGraph(dep.KG)
    c.JSON(http.StatusOK, ProvenanceGraph{Nodes: nodes, Edges: edges})
}
```

**Error handling**:
- 403 via `requireAdmin(c)` gate
- 503 if ontology not wired
- On store/nil report: 503 with message "report not available" (boot hasn't run yet, or validation failed)
