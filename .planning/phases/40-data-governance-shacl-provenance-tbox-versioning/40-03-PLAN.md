**New provenance helper** (package-level, not exported — called inside BuildTriples):
```go
func buildProvenance(note Note) *store.Provenance {
    var srcPath string
    var startLine, endLine int
    if len(note.Sections) > 0 && len(note.Sections[0].SourcePaths) > 0 {
        srcPath = note.Sections[0].SourcePaths[0]
    }
    if note.ChunkMeta.StartLine > 0 {
        startLine = note.ChunkMeta.StartLine
        endLine = note.ChunkMeta.EndLine
    }
    return &store.Provenance{
        SourceKind:  "file",
        SourcePath:  srcPath,
        LineStart:   startLine,
        LineEnd:     endLine,
        ExtractedAt: time.Now().UTC().Format(time.RFC3339),
    }
}
```

Modify `BuildTriples`:
- Build provenance once: `prov := buildProvenance(note)`
- Attach to note type triple: `Triple{S: noteIRI, P: rdfTypeIRI, O: ns+"NoteChunk", Provenance: prov}`
- Attach same `prov` to each referencesTable triple
- Attach same `prov` to each TableSchema type triple
