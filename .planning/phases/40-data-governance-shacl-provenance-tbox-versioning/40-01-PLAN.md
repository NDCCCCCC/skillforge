Implement `Validate(store *store.Store, shapesPath string) (*Report, error)` in validate.go per D-SHACL-01 (pure Go, no third-party Go SHACL library):

**ViolationSeverity enum**: `error` | `warning`
**Violation struct**: `{Severity, Entity, Constraint, Detail, SourcePath, LineStart, LineEnd}`

**7 constraint types to implement** (add switch cases as D-SHACL-04 expands shapes):
1. `sh:minCount` — count property triples; if count < minCount → error
2. `sh:maxCount` — if count > maxCount → error
3. `sh:class` — O must be rdf:type of class IRI; check via store.Query("", rdf:type, classIRI)
4. `sh:datatype` — literal O must have matching XSD datatype (parse xsd:string, xsd:integer, xsd:boolean)
5. `sh:nodeKind` — IRI (must look like a URI), BlankNode (_:), Literal
6. `sh:pattern` — regex match on string value
7. `sh:in` — value must equal one of enumerated list

**Validation flow**:
1. Parse shapesPath via turtle.Parse (goRDFlib) → walk all sh:NodeShape subjects
2. For each NodeShape, identify target class (via `sh:targetClass` or infer from context)
3. Collect all individuals of that class from KG (store.Query("", rdf:type, classIRI))
4. For each individual, evaluate all sh:property constraints
5. Collect violations: structural (class missing, wrong type) → error severity; missing optional (provenance absent) → warning severity
6. Return Report: {Health: "ok"|"warn"|"error", ErrorCount, WarningCount, Warnings[], Quarantined[]}

**Key design decisions per D-SHACL-02/03**:
- Error severity = entity quarantined (added to Quarantined list, NOT included in main index)
- Warning severity = entity allowed through with violation recorded
- Health = "error" if any quarantined; "warn" if warnings only; "ok" if 0 violations
- Provenance-missing is a warning (D-PROV-10存量数据处理)
