# Phase 260817-i36 Plan 01: Chat Answer-Area Four UI Fixes (Verdict-B) Summary

**One-liner:** conclusionText punctuation normalization + chunk-disambiguated doc-chip titles + clickable doc chips as the single chat citation UI (slim chat VerdictCard, null for clean ok-factual) + 「已给出」 demoted to a corner badge on the conclusion text.

## What Was Built

| # | Fix | Where |
|---|-----|-------|
| ④ | `conclusionText` strips trailing sentence punctuation (`。 . ！ ! ？ ?`) from `Verdict.Answer` before the `结论：%s。` template; shared `normalizeConclusionPunctuation` pass collapses any residual `。。` in both branches | `internal/server/chat.go` |
| ③ | New pure fn `titleFor` — `<source path> · chunk <id>` on hit, bare chunk ID on `sourcePathFor` miss (no `9 · chunk 9` self-repeat); `emitVerdictStream` wires Title through it; FE drops the legacy `doc: ` prefix | `chat.go`, `SourceDocumentPart.tsx` |
| ② | Doc chips are now `<button>`s dispatching `setCenterView({kind:'chunk-source', ...})` (normalizeChunkID + extractChunkMetadata, same contract as the citation superscript); VerdictCard in chat context (chatText defined) omits StatusBadge / 「N 条引用」 / CitationCluster but keeps compliance + review-required badges; DataPolicyPart returns null for clean ok-factual-in-chat; CenterPanel path (no chatText) unchanged | `SourceDocumentPart.tsx`, `VerdictCard.tsx`, `DataPolicyPart.tsx` |
| ① | TextPart optional `verdictStatus` prop renders the platform Status as a small corner badge (`absolute -top-2 left-0`, 10px) on the conclusion text; MessageBubble lifts `Verdict.status` off the data-policy part via `isVerdict` and plumbs it through `renderPart`; absent prop = byte-identical output | `TextPart.tsx`, `MessageBubble.tsx` |
