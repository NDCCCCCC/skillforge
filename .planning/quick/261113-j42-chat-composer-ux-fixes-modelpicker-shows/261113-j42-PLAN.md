# 261113-j42 PLAN — 聊天输入框三项 UX 修复

## 背景（勘察已锁定，勿重复勘察）

用户截图反馈三个问题：
1. **模型名显示成 `…`**：`ModelPicker.tsx:228` `{model || (mode === 'stub' ? 'stub' : '…')}` —— env 来源时 `/api/admin/llm/config` 的 `config.model` 可能缺省（`data.config?.model ?? ''`，:82），mode=live 但 model 空 → 只剩省略号；模型列表拉取失败（静默 catch，:101）时也走这个分支。
2. **textarea 不随多行增高**：`ChatInput.tsx:386` 固定 `rows={1}`，`theme.css:1251` `.composer-textarea` 有 `min-height:56px; max-height:200px` 但无 auto-grow 逻辑，多行内容出现内部滚动而不是撑高。
3. **右侧滚动条丑**：`.composer-textarea` 溢出时是浏览器原生滚动条，无任何样式定制。

## Task 1 — ModelPicker 显示兜底

**files:** `web/src/components/chat/ModelPicker.tsx`

**action:**
- :228 改为三层兜底：`{model || (mode === 'stub' ? 'stub' : '未设置模型')}`，并给该 span 加 `title` 提示（如 "模型名未配置 — 在 admin「LLM Provider 配置」选择/保存模型"）。
- :210 分支顺带健壮化：`models.length > 0` 且 `model` 为空时，select 里插入 `<option value="">选择模型…</option>` 占位（value 空时不触发 switchModel——switchModel 已有 `if (!next) return` 守卫，天然安全）。
- 不改后端；env 模式下后端返回生效 model 属后端增强，记 backlog。

## Task 2 — textarea auto-grow

**files:** `web/src/components/chat/ChatInput.tsx`

**action:**
- 加 `useRef<HTMLTextAreaElement>` + `useEffect`（依赖 `text`）：
  ```ts
  const ta = textareaRef.current;
  if (!ta) return;
  ta.style.height = 'auto';
  ta.style.height = `${Math.min(ta.scrollHeight, 200)}px`;
  ```
  200 与 CSS max-height 一致；挂 ref 到 `<textarea>`（:371）。rows={1} 保留作为 SSR/首帧基线。清空发送后依赖 text 变化自动回落。

## Task 3 — 滚动条美化

**files:** `web/src/styles/theme.css`

**action:** `.composer-textarea` 块后追加：
```css
.composer-textarea {
  scrollbar-width: thin;
  scrollbar-color: var(--color-surface-3) transparent;
}
.composer-textarea::-webkit-scrollbar { width: 6px; }
.composer-textarea::-webkit-scrollbar-track { background: transparent; }
.composer-textarea::-webkit-scrollbar-thumb {

  background: var(--color-surface-3);

```
（若 `--color-surface-3`/`--color-text-dim` 变量名不存在，先在 theme.css 里 grep 确认实际变量名再用。）
