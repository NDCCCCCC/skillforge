# 261113-l57 PLAN — scripts/rebuild.ps1 一键重建脚本

## 背景

用户在对话中询问"重新构建是直接运行 build-release.ps1 吗"。答案是否：build-release.ps1 只出发布双平台后端二进制（dist/），且 run.bat 只在 `bin\skillforge-server.exe` 不存在时才构建——改了代码不重建会"改了没生效"。需要一个日常迭代用的一键重建脚本，与 run.bat 配套。

## 任务（单文件 + 文档收口）

**files:**
- `scripts/rebuild.ps1`（新建）

**action:** 脚本行为：
1. 前置检查：`gcc` 在 PATH（duckdb CGO 需要），缺失时报错并指向 `scripts/check-duckdb-toolchain.ps1`；`node`/`npm` 存在性检查
2. Step Web：`Push-Location web; npm run build; Pop-Location`（vite build → web/dist，产物由 Hertz 同源托管）；失败即停
3. Step Server：`go build -o bin\skillforge-server.exe ./cmd/server`（与 run.bat 的 `$bin` 路径一致）；失败即停
4. 可选参数 `-SkipWeb` / `-SkipServer` 跳过对应步骤
5. 成功后提示：启动/重启用 `scripts\run.bat`；**不代启进程**（run.bat 前台运行是唯一受管启动方式；若 8888 已有旧服务在跑，提示先 Ctrl+C 停掉旧的再 run.bat，脚本不杀进程）
6. 风格对齐 build-release.ps1（$ErrorActionPreference='Stop'、Write-Host 进度、退出码语义）

**verify:** 实际运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\rebuild.ps1` 全流程 exit 0，web/dist 与 bin\skillforge-server.exe 更新时间戳刷新。
