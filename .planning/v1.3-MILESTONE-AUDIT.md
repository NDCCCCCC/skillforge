## Deferred REQs

### ROBUST-03 (`hitl_report_publish` raw bytes vs `json.Marshal`)
- **Status:** Intentionally **NOT changed** — re-marshal is a deliberate design choice
- **Rationale:** The existing `json.Marshal(parsed)` re-encode adds `parsed.TemplateVersion = report.TemplateHash(...)` so the frozen bytes carry a stable hash. This is a "moat" for stable operator review.
- **Alternative considered:** Using raw bytes would lose the stable TemplateVersion contract.
- **Documented in:** `.planning/phases/37-store-robustness-concurrency/37-SUMMARY.md`

### STORE-02 UNIQUE constraint (partial)
- **Status:** `ON CONFLICT` clause added but no-op until UNIQUE constraint added to DDL
- **Reason:** SQLite `ALTER TABLE ADD CONSTRAINT` is restricted; requires CREATE TABLE migration
- **Follow-up:** v1.3.1 hygiene phase

### Other 1 REQ (audit-stated but pre-completed)
- The audit reported some REQs (e.g. extra LRU sites) that Phase 33 SRP refactor already resolved. 33 of the original 59 findings closed in earlier phases, not v1.3.
