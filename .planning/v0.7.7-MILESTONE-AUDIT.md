# Milestone v0.7.7 — Audit Report

**Milestone:** SkillForge v1 (7-phase MVP, mvp mode)

## Headline

The milestone is **mid-flight** (3/7 phases) and the three built phases, while each individually green on their own test suites, **do not integrate**. The compliance Q&A flow — the milestone's namesake value — has **never run end-to-end**, and three concrete blockers prevent it from working in production today:

1. **Prod chat 400s on every request** — AI SDK v7 sends `{messages:[...]}`; Hertz decodes `{query, skill}` and rejects empty `query`.
2. **Citations render "(chunk not found)" in prod** — no API exposes chunk text/version/effectiveDate; the `source-document` wire frame carries none of it.
3. **The FE↔BE seam has zero E2E coverage** — no Playwright/integration test, no documented manual run. The one "transport swap" test stubs the network out.

Additionally, **Phases 2 and 4 were never formally closed** — neither has a `VERIFICATION.md` (`/gsd:verify-work` was never run on them), even though both are functionally complete with strong evidence (Phase 4: VALIDATION 83/83 + UAT 12/12 + SECURITY 7/7).

## Recommended Closure Path

The gaps fall into three buckets, each with a distinct fix:

1. **Verification gates (cheapest, do first):** run `/gsd:verify-work 2` and `/gsd:verify-work 4` to produce the two missing `VERIFICATION.md` files. Both phases have the evidence already (Phase 2: needs its VALIDATION reconciled; Phase 4: already fully evidenced). This converts 5 "partial" requirements and closes the formal-verification gap with no code change.
2. **Integration blockers (the real work):** these are the milestone-defining fixes. Recommended as a dedicated closure phase:
   - Add a `prepareSendMessagesRequest` adapter on the prod transport (or relax `chatRequest` to accept v7 `messages`) — fixes FEUI-01.
   - Add `/api/chunks/:id` **or** stream chunk text+version+effectiveDate inline on the `source-document` frame — fixes FEUI-03 / KNOW-05 / CMPL-03.
   - Wire `SkillPicker` to `GET /api/skills` (and add `id`/`name` to Manifest, or align the FE to the 7-field shape) — fixes FEUI-04 / SYSK-03.
   - Add **one Playwright E2E test** driving the real Hertz+React loop — closes the never-exercised-seam blocker and proves the milestone's defining flow.
3. **Unbuilt phases (roadmap):** Phases 3/5/6/7 remain the bulk of unsatisfied requirements (34/55). These proceed via the normal phase chain — Phase 3 (Agentic RAG) is next per dependencies and also delivers the BE emission for FEUI-02/FEUI-06.
